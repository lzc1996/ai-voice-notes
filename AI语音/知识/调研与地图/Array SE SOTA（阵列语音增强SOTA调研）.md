# Array SE SOTA（阵列语音增强SOTA调研）

> [!abstract] 结论先行
> 截至 **2026-10-28**，阵列语音增强不存在跨协议的统一 SOTA。把「SOTA」当成一个榜单会立刻读错，因为当前至少有三条互不通约的战线，任何一条的冠军换到另一条上都不成立。
>
> 1. **已知几何、有监督、以真实录音评测**：**TF-GridNet** 仍是精度锚点（RealMAN 8 kHz 固定阵列 SI-SDR **5.29 dB**、PESQ 2.72），**SpatialNet** 用约 **1/12** 的算力换到 5.23 dB，是效率锚点。2026 年的增量不在「再刷 0.1 dB」，而在效率线与真实数据训练。
> 2. **真实录音与挑战赛**：**CHiME-9 ECHI**（2026，IWAENC）把「助听器 4 麦 + Meta Aria 眼镜 7 麦、算法延迟 ≤ 20 ms、名次由主观可懂度与质量决定」推到主舞台。其 overview 的核心结论是**客观指标不能预测听感**——这是本年度对阵列增强评测最重要的一句话。
> 3. **阵列无关 / 可变麦数**：这一条已有专页 [[Array-Agnostic SE SOTA（阵列可变语音增强SOTA调研）]]，主表 16 行；代价主要落在 SI-SDR（同条件固定阵列上界高约 **1.1 dB**），听感维度几乎不掉。本页不重复其清单，只补它与固定几何线的接口。
>
> 两条支线要单独看：**阵列 TSE**（DOA 或注册语音引导）在跨几何上仍明显弱于匹配阵列上界；**生成式阵列前端**要分两类——直接建模（AMDM-SE 在 CHiME-3 上 PESQ 2.58，对 SGMSE 1.96）与「判别前端 + 扩散精修」（ArrayDPS 家族，相对同一前端只有 **+0.2 dB** 量级，不是相对 noisy 的 7–8 dB）。
>
> 读法只有一句：**先看终点（MOS / SI-SDR / WER），再看测试阵列是否在训练分布内，最后才看数字大小。**

## 1. 判定口径与检索范围

### 1.1. 这里的 SOTA 指什么

本页回答的是「**在某一任务、某一训练/测试协议下，哪些方案有领先或特别有部署价值的作者报告结果**」，不是跨任务总分榜。入选满足以下至少一项：

- 在原文同条件对照中领先，且能核到完整表格；
- 在真实录音、低延迟、低算力、未见设备等关键维度上提供独特证据；
- 作为限定协议的强基线或工程起点，有明确比较价值。

「作者自称 SOTA」不构成入选依据；正式发表、预印本、只有摘要三种证据分开标注；**同行评审不等于结果被独立复现**。

### 1.2. 任务必须拆开

| 任务 | 本页含义 | 不能与什么混排 |
| --- | --- | --- |
| SE | 单目标增强：降噪、去混响，目标可能是直达路径或含混响语音 | 分离的 SI-SDRi、TSE 的说话人相似度 |
| SS / CSS | 多人分离 / 连续分离；CSS 常以 WER 为终点 | 单目标 SE 的 PESQ、SDR |
| TSE | 目标说话人提取；条件可以是 DOA、注册语音或视觉 | 无条件的通用 SE |
| 去回声 / 全双工 | 有播放参考的 AEC + 增强联合 | 无参考的降噪 |
| 生成式精修 | 用混合与判别前端输出做扩散/flow 精修 | 独立前端成绩；增益口径见 §7 |
| 阵列无关 | 横切属性：可变麦数 / 未见几何 / 坏麦 | 固定几何的峰值成绩 |

采样率、目标信号、训练数据、测试几何是否见过、麦数、说话人数与指标定义必须一致，才能做严格横向排名。

### 1.3. 证据等级

- **A｜正式论文 + 全文表格**：可核到出版信息与结果表；
- **B｜预印本 + 全文表格**：可核到表，但不能写成已接收；
- **C｜摘要级**：只记录作者主张，不据此给定量冠军。

本页只做分协议调研，不是 PRISMA 式穷尽综述，也不是同条件复现横评。

## 3. 固定几何主线

### 3.1. TF-GridNet：仍是锚点，不是过去时

**证据：A（IEEE/ACM TASLP 2023）。** [[方向/AI语音/模型/TF-GridNet]] 把 full-band、sub-band 时序建模与 cross-frame self-attention 组合在 STFT 网格上做复数谱映射。它在 2026 年仍被反复当作三类东西：固定阵列上界（§2.1 的 5.29 dB）、生成-预测混合系统的预测分支（[[方向/AI语音/模型/GAP-URGENet]]）、以及 CHiME-9 ECHI 官方基线骨干。

这不是「没有进步」，而是**它成了度量单位**：新工作要么在同一协议上超过它，要么用更少算力逼近它。前者的公开证据稀少，后者在 2026 年变多（§3.4）。

### 3.2. SpatialNet：1/12 算力的第二锚点

**证据：A（IEEE/ACM TASLP 2024）。** [[方向/AI语音/模型/SpatialNet]] 不手工构造 IPD/ILD、也不显式估计导向矢量，只从多通道复谱学空间信息；small 1.2M、large 6.5M。在 §2.1 的同表里，1.2M / 5.99 G/s 的 SpatialNet 拿到 5.23 dB，与 8.2M / 73.03 G/s 的 TF-GridNet 只差 0.06 dB。

**工程含义**：如果部署约束是算力而不是峰值，SpatialNet 是当前性价比最高的固定几何前端；它的代价是对「同位置双说话人」这类空间线索失效的场景退化明显（原文 SDR 15.1→8.8 dB）。

### 3.3. USES2 与「阵列无关的代价」

USES2-comp 在同一张表里是可变麦基线：2.5M / 70.26 G/s、4.17 dB。它比固定阵列上界低约 1.1 dB，但比 FaSNet-TAC 高近 5 dB。**这条差值线是判断任何「阵列无关新方法」的标尺**：声称泛化而不在同一协议下报这 1 dB 代价的工作，证据是不完整的。

### 3.4. 2026 效率线：把算力打下来，而不是把分数打上去

| 工作 | 事实 | 证据边界 |
| --- | --- | --- |
| **PS² / Moving-Sep**（2026·B） | 双分支并行频谱-空间，BLSTM + Mamba + 自注意力；移动说话人场景 SI-SDR 比 SOTA 高 **1.6–2.2 dB** | 原文 Table VI 给出 **8.4M / 66.8 G/s**，同表 TF-GridNet 为 14.5M / 463.7 G/s（六通道实验配置；WSJ0-2mix 单通道原论文为 14.4M） |
| **GTCRN 系** | 超低算力单通道前端，已被多通道化改造 | 原始论文与多通道变体的 RealMAN 结果未在本页核实，不作定量引用 |
| **LABNet / CaSNet** | 52k 参数级阵列前端，RealMAN 6 麦 PESQ 2.34 / 2.27 | 见旧页 §2.3；容量不是瓶颈的直接证据 |

结论：**2026 年固定几何线的真实竞争在「同等分数下少一个数量级的算力」**，而不是分数本身。这也解释了为什么「SOTA」这个词在这一线越来越没有信息量——同一分数档里可能有 1.2M 和 8.2M 两个模型。

### 3.5. 传统-神经混合链：工程下界不能省

mask-MVDR、pDNN-WPD / DNN-WPD、MISO 一类混合链在论文里常被当作 baseline，但它们的价值是**可解释、可实时、可定位失败**。任何神经端到端系统如果只在 PESQ 上赢 0.2，而在 WER 或空间保真上输给 mask-MVDR，就不构成部署理由。本页建议把「同数据 mask-MVDR」固定为每张表的最后一行，这一条比再补一个模型更有用。

## 4. 真实录音与挑战赛

### 4.1. CHiME-9 ECHI：把「客观指标失灵」变成赛制

**证据：A（IWAENC 2026 overview，arXiv:2609.26306）；任务页与数据见 [[方向/AI语音/评估/ECHI（助听对话增强）]]。**

- **场景**：4 人围桌、餐厅噪声 + 竞争对话 + 环境音效；设备是 **Meta Aria 眼镜（7 麦）** 与 **WSA 助听器（4 麦，左右耳各前/后）**，两类设备必须独立处理。
- **硬约束**：因果/流式，算法延迟 ≤ **20 ms**；每场输出每个对话伙伴一条单通道流（3 条），可重加和。
- **数据**：每场 36 min，train 30 / dev 10 / eval 8，共 **48 场**（overview §2；[[方向/AI语音/评估/ECHI（助听对话增强）]] 旧记为 49 场 / eval 9，引用时以 overview 为准）；说话人与噪声环境完全不相交；每名参与者有 Rainbow Passage 注册语音。
- **评测**：客观用 VERSA（STOI/PESQ/SDR/SI-SNR/FWSEGSNR + DNSMOS/NISQA/UTMOS/SQuIM），只作参考；官方名次由**主观可懂度（转写正确率）与质量（连续 1–5 分锚点评分）**共同决定，不以客观指标定榜（挑战页口径称 MUSHRA 式听测，具体量表以实现报告为准）。
- **结果**：7 支队伍；overview 明确「客观指标不能反映听者表现」，但头部系统在可懂度与质量上都显著超过官方基线（baseline 为因果化 TF-GridNet + 说话人编码器 + FiLM，dev 重加和 FWSEGSNR 从 ~1.2–1.4 提到 ~3.3）。

**为什么这条最重要**：它把阵列增强的评价从「PESQ 涨了多少」拉回「人能不能听懂」。对做阵列前端的人，这意味着两件事：第一，20 ms 因果约束会淘汰大多数离线掩码 SOTA；第二，任何只报 PESQ/STOI 的阵列论文，在助听/穿戴场景下的外推能力是未知的。

### 4.2. CHiME-8 / NOTSOFAR-1：已知几何的下游收益，但不是增强榜

CHiME-8 的 NOTSOFAR-1 提供约 280 场真实会议 + 1000 h 仿真，多通道 track 使用单个已知几何的圆形阵列设备，终点是 tcpWER 与 diarization。它适合回答「阵列前端能不能降低转写错误」，**不能**回答「增强质量好不好」。同届 DASR 的冠军系统（NTT）tcpWER 22.0%，其前端仍是 GSS 系多通道处理 + 强 ASR 组合——说明在真实会议线上，**前端收益很容易被后端 ASR 吸收**。

### 4.3. RealMAN：真实阵列增强的默认评测场，但缺统一协议

[[RealMAN]] 是 32 通道单阵列、83.7 h 语音 + 144.5 h 噪声的真实录制集（NeurIPS 2024），clean 目标是直达路径语音，测试集按实录电平自然混合（test 平均 SNR ≈ −0.8 dB）。

它的价值与陷阱同样明显：

- **价值**：唯一被广泛用于「真实录音 + 可变子阵」的公开集；Geo-DConv、Uni-ArrayDPS、CaSNet 都在它上面报结果。
- **陷阱**：**未发现官方 leaderboard 或统一评测协议**，混噪 SNR 在原文、仓库配置、下游论文三处不一致（训练区间有 [0,15] 与 [−10,15] 两版）；同一张「RealMAN 表」可能对应 8 kHz 随机 ≤4 麦、16 kHz 固定 5 麦、或 static 子集自混三种协议。跨论文引用前必须核协议，见 [[方向/AI语音/评估/RealMAN 测试结果清单]]。

### 4.4. URGENT 不是阵列榜

ICASSP 2026 URGENT 官网只有 Track 1（universal SE）与 Track 2（语音质量评估），**没有阵列 track**；Track 1 的输入是单路语音，不处理多通道阵列。因此 [[方向/AI语音/评估/URGENT（通用语音增强挑战）]] 的排名（如 GAP-URGENet 的 PESQ 2.89 / ESTOI 0.90 / DNSMOS 3.31、567.8M 参数）**不能**作为阵列 SE 的 SOTA 证据，只能作为「单通道上限 / 生成-判别融合」的参照。

### 4.5. 工业界：穿戴与会议两条线

- **阿里 / Hummingbird Audio Lab**：CHiME-8 MMCSG 智能眼镜场景，因果多通道 DSE，报告相对 baseline 降低 wearer / partner WER；
- **腾讯 / NPU-TEA**：CHiME-8 NOTSOFAR-1 与 MMCSG 的系统工程线，覆盖 streaming 与非 streaming；
- **科大讯飞 + USTC-NERCSLIP**：CHiME-9 MCoRec 冠军（360° 音视频、AVTSE/AVSR + LLM 融合），连续第六届 CHiME 夺冠；ECHI 侧是否参赛待核。

工业方案的可比性普遍低于学术论文：多数只报 WER 或内部指标，不给阵列配置与延迟预算。

## 5. 阵列无关：与固定几何线的接口

旧页已给出完整清单与逐行测试条件，这里只保留三条**接口结论**，避免两页重复：

1. **代价是 1 dB 量级，不是 10 dB**：同协议下固定阵列上界 5.23–5.29 dB，可变麦基线 4.17 dB；SpatialNet/TF-GridNet 改造成 Geo 版后分别落在 4.22 / 3.90 dB。
2. **听感维度几乎不掉**：Geo 版 SIG/OVRL 与固定版基本持平甚至略高（OVRL 2.68 vs 2.67、2.77 vs 2.71），掉的是 SI-SDR——说明损失集中在波形精细结构与相位，而不是谱包络与噪声抑制。
3. **真实数据 + 可变麦数 + DNSMOS 三者同时满足的仍只有 Geo-DConv**；AmbiDrop 有代码与广几何证据，但训练几何上 SI-SDR 反而降 0.87 dB；UniArray 只有仿真分离。

**孔径不能靠虚拟麦补回**。[[方向/AI语音/模型/Spatial-Magnifier]] 在固定 6 麦阵列上做「少麦上采样」：只用 2 个真实麦再生成 4 个虚拟麦（2RM+4VM）时 SI-SDR 为 **4.89**、PESQ 2.24，而直接 6 麦 SpatialNet+MCWF 是 **5.84** / 2.36；2 个真实麦的基线只有 3.14 / 2.13（Table 3）。虚拟通道能补回大部分**空间采样**收益（+1.75 dB），但补不回**真实孔径**带来的最后 0.95 dB。这对「麦数越少越好」的阵列无关叙事是一个硬约束。

选型结论沿用旧页：已知坐标优先 Geo-DConv；广几何/坏麦/要跑通优先 AmbiDrop；单阵列训练跨形状看 DeFTAN-AA；不要用一个「array-agnostic SOTA」的说法覆盖这四种需求。

## 6. 阵列目标说话人提取（TSE）

**证据：B（GC-SSF，arXiv:2605.18442）；其余为任务页证据。**

- GC-SSF（[arXiv:2605.18442](https://arxiv.org/abs/2605.18442)）把麦克风位置与目标 DOA 联合编码，经 FiLM 调制空间选择性滤波器；固定 4 麦、WSJ0 仿真。跨几何 PESQ 为 2.53 / 2.41 / 2.46（Circ / ULA / Random），而匹配 Circ 训练的 SSF-Circ 在 Circ 上是 2.95。**它证明的是几何条件化的迁移收益，不是取代匹配阵列上界。**
- CHiME-9 ECHI 是当前规模最大的**注册式阵列 TSE** 公开评测：Aria 7 麦 + 助听器 4 麦、20 ms 因果、主观听测定榜，且明确禁止使用 dev 调参与非流式全局信息。
- 共同缺口：**跨阵列几何 + 注册语音 + 低延迟三者同时成立的工作几乎没有**；GC-SSF 不支持变麦数，ECHI 系统多为比赛定制、未开源。

对做产品的人，这条线的现实选择是：几何已知 → 空间滤波器/波束形成 + 注册嵌入；几何未知 → 先降级为单通道 TSE，再接受阵列增益损失。

## 7. 生成式阵列前端

**证据：B（AMDM-SE、Uni-ArrayDPS）；A（mSGMSE，ICASSPW 2024）。**

- **AMDM-SE**（2026-01，Opochinsky & Gannot）：跨通道时频注意力 + 扩散，任务是降噪。CHiME-3 真实 6 麦上 PESQ 2.58 / eSTOI 0.91 / OVRL 3.158，优于 SGMSE（1.96 / 0.84 / 3.128）与无注意力的多通道扩散；仿真集 PESQ 3.11、SI-SDR 7.06。它是「生成式直接吃多通道」的代表，但只在 CHiME-3 一个真实集上验证。
- **ArrayDPS 家族**（[[方向/AI语音/模型/Uni-ArrayDPS]]）：判别前端 + 干净语音扩散先验 + 噪声 SCM 观测约束，推理时把阵列信息放进似然。**真实增益只有相对同一前端的 +0.21 / +0.20 dB**（RealMAN 4/8 麦），代价是 300 步采样与一个额外先验。
- **mSGMSE**：联合生成所有通道，天生保 ITD/ILD，但通道数固定，属于「生成式自己造空间线索」的另一端；demo 的 ensemble 变体 RTF 7.87，不是常规成本。

结论：生成式在阵列线上的角色是**精修器**，不是前端替代品。判断它是否值得，唯一口径是「同前端、同采样预算下的增量」，而不是「相对 noisy 的增益」。

## 8. 按场景选型

| 场景 | 首选验证对象 | 代价与前置条件 |
| --- | --- | --- |
| 已知固定几何、真实录音、要精度 | [[方向/AI语音/模型/TF-GridNet]] | 8.2M / 73 G/s，非轻量；需与 SpatialNet 对比再定 |
| 已知固定几何、算力受限 | [[方向/AI语音/模型/SpatialNet]] | 1.2M / 5.99 G/s，峰值低 0.06 dB；同位置双人场景退化 |
| 麦克风坐标可用、阵列会换 | [[方向/AI语音/模型/Geo-DConv]] | 需坐标标定；无官方代码；未见 5 麦时不如 USES2 |
| 多设备/不规则阵列、可能坏麦 | [[方向/AI语音/模型/AmbiDrop]] | 需 ASM/ATF；训练几何上 SI-SDR 略降 |
| 助听器 / 眼镜、20 ms 流式 | CHiME-9 ECHI 系统族（TF-GridNet 因果基线起步） | 必须因果；主观听测定榜，客观指标不足以选型 |
| 会议转写前端 | GSS / mask-MVDR + 强 ASR | 终点是 tcpWER，增强收益易被后端吸收 |

| 多人分离、移动说话人 | PS² / Moving-Sep | 动态场景专用；静态 SE 不适用 |

## 9. 建议的统一横评协议

1. **先锁任务与终点**：SE / SS / TSE / 去回声分表；MUSHRA、SI-SDR、WER 不混排。
2. **阵列按几何留出，不只按麦数**：seen geometry/seen M、seen geometry/unseen M、unseen shape/seen M、unseen shape/unseen M 四档。
3. **固定阵列上界必须同表**：没有「同数据、同参数档的固定阵列对照」，就无法量化阵列无关的代价。
4. **真实与仿真都给**：至少一个真实多阵列集（RealMAN）与一个真实挑战赛集（CHiME/ECHI）。
5. **延迟与因果单列**：20 ms 流式与离线非因果不能同榜；ECHI 已把 20 ms 因果写进规则，而不是当作可选项。
6. **成本口径统一**：参数、MACs、RTF、显存、采样步数，且包含 ASM/编码器等前端开销。
7. **精修器成对报告**：同前端未精修行必须保留，分开报「相对 noisy」与「相对前端」两个增益。
8. **给不确定性**：多种子、按语句 bootstrap 置信区间；当前文献不足以支持跨方法显著性声明。

## 10. 空白与复现优先级

- **固定几何线缺少 2026 年的同协议新上界**：TF-GridNet/SpatialNet 的 5.2–5.3 dB 仍是 2023–2024 的数；2026 的新工作多在效率或新任务上，没有在同一 RealMAN 协议上刷新峰值。
- **真实多说话人 + 未见几何**仍是空白：ECHI 是真实但固定设备；RealMAN 是真实但单阵列子阵；两者没有交叉验证。
- **助听/穿戴线的可复现性差**：ECHI 系统多为比赛定制，代码与权重未公开；20 ms 约束下的开源基线只有官方 TF-GridNet 因果版。
- **客观-主观失配没有解法**：ECHI overview 明确指出客观指标不能预测听感，但社区仍在用 PESQ 选型；需要至少一个「客观指标 → 主观听测」的校准研究。
- **复现顺序建议**：先跑 SpatialNet（便宜）建立固定几何基线 → 同数据跑 TF-GridNet 确认上界 → 再用 Geo-DConv/AmbiDrop 量化阵列无关代价 → 最后才考虑生成式精修。
