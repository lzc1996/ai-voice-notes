# Array SE Roadmap（阵列语音增强技术路线优先级）

这页把 [[方向/AI语音/知识/调研与地图/Array Speech Enhancement Frontier（阵列语音增强前沿调研）]] 拆成**技术预研优先级**。当前定位是围绕大模型和生成式建模做中长期预研，不按短期上线、端侧耗时或近期工程闭环排序；优先追踪能改变多通道增强能力上限、泛化边界、空间表示和任务形态的路线。已单独展开的路线包括：[[方向/AI语音/知识/技术路线/Hybrid Array SE（传统神经混合阵列增强）]]、[[方向/AI语音/知识/技术路线/Generative Multichannel SE（生成式多通道语音增强）]]、[[方向/AI语音/知识/技术路线/Efficient Multichannel SE（多通道语音增强高效化）]]、[[方向/AI语音/知识/技术路线/Array-Agnostic SE（阵列无关语音增强）]]、[[方向/AI语音/知识/技术路线/Real-Data Array SE（真实数据驱动阵列增强）]]、[[方向/AI语音/知识/技术路线/Distributed Multichannel SE（分布式异步多通道增强）]]、[[方向/AI语音/知识/技术路线/Spatial-Guided SE（空间引导与多模态增强）]]。

总判断：**先研究能力上限，再处理工程约束**。当前最值得投入的是生成式多通道建模、阵列泛化 / 少麦空间表示、真实数据闭环、空间/语义条件化和大模型可接入的多通道表示；高效化暂时只做复杂度记录和可复现实验，不作为淘汰高上限路线的排序条件。

## 1. 优先级

| 优先级 | 路线 | 预研判断 | 主要入口 |
|---|---|---|---|
| P0 | 生成式多通道 | 最贴近大模型预研主线：研究多通道后验、语音先验、空间一致性、幻觉约束和观测一致性；不因采样成本高而后置 | [[方向/AI语音/知识/技术路线/Generative Multichannel SE（生成式多通道语音增强）]] |
| P1 | 阵列泛化 / 任意几何 / 少麦 | 决定多通道能力能否从单一设备扩展到通用空间表示；需拆分未知几何、已知坐标条件化、固定几何少麦上采样三类口径 | [[方向/AI语音/知识/技术路线/Array-Agnostic SE（阵列无关语音增强）]] |
| P2 | 真实数据 / 弱监督 / 无监督 | 决定生成式与大模型式增强是否真的学到真实声学规律；同时提供幻觉、空间失真和域外偏移的验证闭环 | [[方向/AI语音/知识/技术路线/Real-Data Array SE（真实数据驱动阵列增强）]] |
| P3 | 空间引导 / 多模态 | 把增强推进到“按人、按方向、按语义条件生成/抽取”，与语音 Agent、speaker attribution 和多模态大模型接口最强 | [[方向/AI语音/知识/技术路线/Spatial-Guided SE（空间引导与多模态增强）]] |
| P4 | 分布式 / 异步 / 柔性阵列 | 研究观测集合从固定阵列变成动态设备网络；变量多、验证重，但对未来多设备感知和大模型环境理解有战略价值 | [[方向/AI语音/知识/技术路线/Distributed Multichannel SE（分布式异步多通道增强）]] |
| P5 | 传统-神经混合 | 不作为主攻范式，但必须保留为物理约束、可解释 baseline、观测一致性接口和生成式模型的安全边界 | [[方向/AI语音/知识/技术路线/Hybrid Array SE（传统神经混合阵列增强）]] |
| P6 | 端侧 / 流式 / 高效化 | 当前只记录复杂度、NFE、流式性和潜在蒸馏路径；不把低延迟作为预研路线排序的一票否决项 | [[方向/AI语音/知识/技术路线/Efficient Multichannel SE（多通道语音增强高效化）]] |

## 2. 取舍逻辑

- **P0 是大模型化主线**：比较直接多通道扩散、判别式前端 + 生成式 refiner、经典信号处理耦合、flow / one-step corrector 和可能的 codec / latent 方案；核心问题是“模型生成了什么、是否符合阵列观测、是否保持空间关系、是否能被上层语义模型条件化”。
- **P1 是表示主线**：比较 Ambisonics / eigenbeam 规范空间、显式坐标条件化、raw mic + beamformer 混合、固定已知几何下的空间上采样；核心问题是“空间先验应显式保留、规范化后学习，还是变成可被大模型消费的 token / latent”。
- **P2 是科学有效性主线**：真实数据不是后期验收项，而是验证模型是否学到真实声学规律的必要条件；[[方向/AI语音/模型/Mixture to Beamformed Mixture（波束形成混合弱监督）]]、[[方向/AI语音/模型/USDnet++]] 和 RealMAN 应与生成式模型研究同步。
- **P3/P4 是任务和观测边界扩展**：空间引导把输出从目标语音推进到说话人归属、方向条件和语义条件；分布式阵列把观测从固定阵列推进到动态设备集合。
- **P5 是物理底座**：WNG、MVDR、DP-MWF、WPE、SCM 估计用于构造强 baseline、观测一致性约束、可解释消融和生成式模型的回退边界，不应因为“传统”而跳过。
- **P6 是后置工程化**：[[方向/AI语音/模型/Mel-McNet]]、[[方向/AI语音/模型/ARiSE]]、[[方向/AI语音/模型/CUSIDE-array]] 仍保留为复杂度参照，但当前不以端侧 RTF、流式性或短期部署成本作为淘汰新技术的首要标准。
- **表示级融合是横切主题，暂不单列 P 级**：增强与语音大模型的表示级融合横跨 P0（生成式表示）、P1（空间规范表示能否被大模型消费）、P3（语义条件化）；融合分级（波形级 / 特征级 / 表示级）与阵列特有开放问题见 [[方向/AI语音/知识/调研与地图/Array Speech Enhancement Frontier（阵列语音增强前沿调研）]] "八、增强与语音大模型的表示级融合"。待"多通道空间表示 → SpeechLM token / latent"出现公开实证后再评估是否独立成线。

## 3. 近期工作顺序

1. 深挖生成式多通道：统一比较 direct generation、refinement、model-based coupling、flow / one-step 四类接口。
2. 深挖阵列泛化：做 Ambisonics / eigenbeam / explicit geometry / hybrid cues / 少麦空间上采样的同条件横评，先标清每类是否真的 array-agnostic。
3. 建真实数据闭环：把真实阵列数据、弱监督标签、无监督约束和仿真数据混训串起来。
4. 研究空间任务扩展：DOA / TSE / speaker attribution / AVSR 不再只作为下游，而作为增强条件和输出定义。
5. 研究分布式观测：SRO / STO、动态设备、传输压缩和不完整阵列作为新的测量模型。
6. 完成混合式 baseline：固定 WNG-MVDR、DP-MWF、WPE / CBF、neural covariance 作为所有新路线的可解释对照。
7. 最后处理高效化：在技术路线稳定后再做 NFE、蒸馏、量化、流式和端侧映射；现阶段只记录成本，不反向压缩预研问题。
