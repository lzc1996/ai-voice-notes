# SMS-WSJ Heuristic（SMS-WSJ 启发式）

这不是 SMS-WSJ 官方提出的方法名，而是一张**读论文、拆实验、判断结果能否外推**的工作性检查卡。当前未在原论文、官方仓库及检索到的相关资料中发现名为 “SMS-WSJ heuristic” 的规范术语。

## 1. 先确认基准身份

把 SMS-WSJ 先看成**受控的远场双说话人多通道仿真基准**：8 kHz、6 麦 20 cm 圆阵、随机房间与几何、$T_{60}$ 约 200–500 ms、20–30 dB 空间白传感器噪声。它适合隔离方法机制，但不等于真实设备条件。

## 2. 再确认实验轴

读结果时先问四件事：

- 用了几路麦克风，具体是哪几个通道？
- 是 1 / 2 / 3 / 6 通道中的哪一种口径？
- 训练、验证、测试是否保持相同的阵列与几何条件？
- 是否把不同通道数、不同阵列口径的结果放在同一张表里比较？

如果这些信息没写清楚，先把结果标成**不可直接横比**。

## 3. 把参考信号和指标绑在一起

SMS-WSJ 的核心陷阱不是数字大小，而是参考定义不同：

- **BSS-Eval SDR**：更适合远场混响下允许短 FIR 对齐的比较。
- **SI-SDR**：对通道参考和相位 / 混响差异更敏感，不应与 BSS-Eval SDR 直接横比。
- **源信号、完整镜像、早达镜像**：三者是不同目标；oracle 早达镜像的结果不能当成普通可实现上限。

工作规则：先写清 `metric + reference + channel count`，再看提升幅度。

## 4. 用 WER 检查“听起来更好”是否真的有用

SMS-WSJ 同时提供 Kaldi ASR 基线，因此分离 / 增强结果至少要和 WER 一起读：

- SDR 上升但 WER 不降：可能只改善了波形或残留噪声，内容可识别性没有同步改善。
- WER 改善但 SDR 普通：可能是前端保住了关键语音结构，说明单一分离指标低估了下游收益。
- 只报 PESQ / STOI：不足以证明对识别或真实设备部署有价值。

## 5. 把结论限制在仿真边界内

SMS-WSJ 更适合支持下面这类结论：

- 某个模型能否利用多通道空间线索。
- 某种 mask、波束形成器或时频建模在受控混响下是否有效。
- 指标、参考信号和通道数变化会怎样影响结论。

它不能单独支持下面这类结论：

- 真实阵列、穿戴设备或会议室中的泛化已经解决。
- 对真实相干背景噪声、坏麦、同步误差、阵列失配同样鲁棒。
- 8 kHz 仿真结果可以直接代表 16 kHz 产品体验。

## 6. 一句话判断

**SMS-WSJ 是“机制与评测口径”基准，不是“真实设备就绪”证明。** 看到高分时，先核对数据口径、参考信号、通道数和 WER，再决定它说明了模型能力，还是只说明了实验设置。
