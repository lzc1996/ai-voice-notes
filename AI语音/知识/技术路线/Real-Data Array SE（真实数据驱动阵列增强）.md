# Real-Data Array SE（真实数据驱动阵列增强）

真实数据路线是阵列增强的 **P2**：它不是短期上线验收项，而是大模型 / 生成式多通道预研的科学有效性闭环。模型结构可以很快被复刻，但真实阵列录音、弱标签、筛选规则、评估分桶和失败案例库更难复制。

核心问题：真实多通道录音很难拿到逐样本 clean target；只靠仿真 RIR + 干净语音训练，真实房间、真实设备、真实噪声和通道误差会造成 sim-to-real mismatch。

## 1. 路线拆分

| 路线 | 代表 | 适用判断 |
|---|---|---|
| beamformed mixture 弱监督 | [[方向/AI语音/模型/Mixture to Beamformed Mixture（波束形成混合弱监督）]] | 用真实多通道录音 + beamformer 弱标签研究 sim-to-real 适配 |
| 无监督去混响 / 前向约束 | [[方向/AI语音/模型/USDnet++]] | 用物理前向约束减少 clean target 依赖，给生成式模型提供观测一致性参照 |
| 真实多通道数据集 | RealMAN、CHiME / NOTSOFAR / AMI / AliMeeting | 用真实房间和真实阵列测试泛化、幻觉、空间失真，而不是只看仿真分数 |
| 数据筛选与混训 | [[方向/AI语音/实证研究/Less is More（语音增强数据筛选）]] 口径 | 数据质量和覆盖比盲目堆小时数更重要 |

## 2. 预研价值

- **验证生成式幻觉**：真实低 SNR、混响尾巴、弱辅音、重叠说话能暴露“听起来合理但内容错”的问题。
- **验证空间失真**：真实阵列失配、通道误差、佩戴扰动和房间反射能检验多通道输出是否仍保 ITD / ILD / DOA。
- **提供弱监督锚点**：M2BM / GSS / beamformer teacher 可以给生成式 refiner 提供内容锚点，降低纯仿真训练偏差。
- **校准仿真假设**：真实数据不是替代仿真，而是用来反向修正 RIR、噪声、运动、设备误差的仿真分布。
- **形成失败案例库**：比平均指标更重要的是记录哪些条件下模型改词、变声、空间晃动或目标泄漏。

## 3. 局限

- **弱标签会继承 teacher 错误**：beamformer 选错目标、残留噪声、语音失真都会被 DNN 学进去。
- **真实数据覆盖仍有限**：录音场景、语言、设备、说话人分布不全时，模型会学到数据集偏见。
- **无监督约束可能过强**：前向滤波 / WPE 先验能减少标签依赖，也可能限制非典型房间和强噪声场景。
- **评估不可只看增强指标**：真实转写场景还要看 WER / cpWER、diarization、speaker attribution。

## 4. 验证成本

- **采集成本**：真实阵列录音需要设备、场地、标注和隐私处理。
- **弱标签生成成本**：beamforming / GSS / WPE pipeline 要稳定，否则训练数据会被污染。
- **筛选成本**：需要按 SNR、重叠率、混响、运动、噪声类型、teacher 置信度筛选样本。
- **评估成本**：真实集要拆 seen room / unseen room、seen device / unseen device、仿真 / 真实、短句 / 长会。

## 5. 当前做法

1. 用仿真数据预训练基础模型。
2. 用真实多通道录音生成 beamformed mixture 弱标签。
3. 混入少量高置信真实弱标签做适配实验，而不是直接全量替换。
4. 对弱标签做置信度筛选：低 SNR、目标不明确、beamformer 输出异常的样本单独分桶，不要只丢掉。
5. 评估同时看增强指标、ASR / diarization 终点、内容保持、说话人一致性和空间保真。

## 6. 关键来源

- [Mixture to Beamformed Mixture](https://arxiv.org/abs/2507.15229)：真实录音 beamformed mixture 弱监督。
- [USDnet](https://arxiv.org/abs/2402.00820)：无监督神经前向滤波去混响，USDnet++ 的前作背景。
- [[方向/AI语音/模型/Geo-DConv]]：RealMAN 真实多通道数据集是阵列无关验证的重要入口。
