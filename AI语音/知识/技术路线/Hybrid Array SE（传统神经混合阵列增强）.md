# Hybrid Array SE（传统神经混合阵列增强）

混合式阵列语音增强在当前预研路线里是 **P5 / 物理底座**。它的核心不是“把神经网络接到传统方法后面”，而是明确分工：**神经网络估难建模的统计量，经典滤波器承担物理约束、可解释输出和生成式模型的观测一致性边界**。

关键分水岭只有一个：系统最后要的是**单个干净目标通道**，还是**仍然保留空间结构的多通道声场**。

- [[方向/AI语音/模型/WNG-MVDR|WNG-MVDR]]：目标是稳健的 MISO / 单输出增强，是 ASR、通话上行、会议转写、语音 Agent 前端的强 baseline，也可作为生成式 refiner 的内容锚点。
- [[方向/AI语音/模型/Direction-Preserving MIMO|Direction-Preserving MIMO]]：目标是保留方向线索的 MIMO / 多输出增强，是助听、AR 透传、空间音频、后级 DOA / beamforming 的物理参照，也可作为生成式 MIMO 的空间保真对照。

## 1. 为什么需要“传统 + 神经网络”

纯传统阵列方法的问题不是公式不对，而是真实短窗、多源、移动和失配条件下关键统计量很难稳定拿到：

- 目标 [[方向/AI语音/知识/基础概念/steering vector（导向矢量）|steering vector]] / RTF 会随人移动、近场、佩戴、遮挡、混响早反射而失配。
- 噪声 [[方向/AI语音/知识/基础概念/SCM（空间协方差矩阵）|SCM]] 在短窗内估计不稳，且容易混入目标语音。
- 小阵列低频段自由度不足，追求超指向会牺牲 [[方向/AI语音/知识/基础概念/WNG（白噪声增益）|WNG]]，上真实设备后容易放大自噪声和校准误差。
- 多说话人、非平稳噪声、混响尾巴让固定假设的 VAD / DOA / loading 很快失效。

纯神经增强的问题则相反：它能拟合复杂退化，但缺少硬约束，容易产生语音失真、空间线索塌缩或不可解释的相位重写。

混合式的合理位置是：

1. **NN 估计层**：估 [[方向/AI语音/知识/基础概念/TF Mask（时频掩码）|TF Mask]]、speech/noise SCM、RTF、频变 WNG 阈值、Cholesky 因子或场景状态。
2. **经典约束层**：用 [[方向/AI语音/知识/基础概念/MVDR（最小方差无失真响应）|MVDR]]、WNG-constrained MVDR、[[方向/AI语音/知识/基础概念/DP-MWF（保向多通道维纳滤波）|DP-MWF]] 等线性滤波器执行约束优化。
3. **输出语义选择**：选择 MISO 单输出还是 MIMO 多输出；这一步比网络结构更影响任务定义和后续大模型接口。

一句话：NN 解决“估不准”，经典滤波解决“别乱改”。

## 2. WNG-MVDR：把目标稳稳取出来

[[方向/AI语音/模型/WNG-MVDR|WNG-MVDR]] 的技术含义是：在 [[方向/AI语音/知识/基础概念/MVDR（最小方差无失真响应）|MVDR]] 的目标方向无失真约束上，再用 [[方向/AI语音/知识/基础概念/WNG（白噪声增益）|WNG]] 限制权重范数，防止波束形成器为了压噪而过度放大白噪声和阵列失配。

基本形式：

$$
\min_{\mathbf{w}} \mathbf{w}^{H}\Phi_{nn}\mathbf{w}
\quad \text{s.t.} \quad
\mathbf{w}^{H}\mathbf{d}=1,
\quad
\frac{|\mathbf{w}^{H}\mathbf{d}|^2}{\mathbf{w}^{H}\mathbf{w}} \ge \gamma
$$

无失真约束成立时，WNG 近似就是 $1 / \|\mathbf{w}\|^2$。所以 WNG 不是“又一个质量指标”，而是**设备鲁棒性旋钮**：值高则稳但波束不够尖；值低则压噪强但更容易对麦克风自噪声、位置误差、增益相位误差敏感。

### 2.1. 作为 baseline 的价值

- **机器听 baseline**：ASR、会议转写、语音指令、通话编码上行只需要一个目标流，WNG-MVDR 是必须对照的 MISO 下界。
- **目标方向可靠分桶**：固定座位、唤醒后说话人锁定、摄像头/DOA 跟踪稳定等条件可用来区分“空间估计问题”和“生成式修复问题”。
- **小阵列鲁棒性参照**：WNG 是防止“仿真强、真实设备失配崩”的必要安全阀，可作为生成式模型观测一致性的物理旋钮。
- **短窗因果参照**：NN 可估噪声 mask / SCM，MVDR 层用闭式解输出，给高成本生成式方法提供低延迟对照。
- **可调试前端**：能检查 SCM 条件数、$\mathbf{w}^{H}\mathbf{d}$、WNG 频响、diagonal loading 敏感性。

### 2.2. 优势

- **低目标失真**：目标方向响应被归一为 1，减少网络直接重绘语音带来的内容/音色改写。
- **鲁棒性显式可控**：WNG 把“指向性 vs 失配容忍度”暴露成可检查变量，而不是埋进黑盒。
- **和 NN 分工干净**：NN 估 mask / SCM / WNG 阈值；MVDR 做线性空间滤波。错了能定位是估计层错还是约束层错。
- **对 ASR 友好**：输出是一个稳定目标通道，后端不用处理多通道空间结构。

### 2.3. 局限

- **无失真只保护假定方向**：RTF / steering vector 错时，MVDR 会认真保护错误目标或错误相位关系。
- **WNG 不是免费午餐**：WNG 阈值提高会降低指向性，阈值降低会提高自噪声和 mismatch 风险。
- **mask 泄漏会伤目标**：短窗或重叠说话时，噪声 SCM 混入目标语音，MVDR 可能把目标当噪声抵消。
- **MISO 会压扁空间**：输出单通道后，残留噪声方向、声场相干性和双耳线索基本不可恢复。
- **同方向干扰弱**：目标和干扰 DOA 接近时，空间自由度不足，WNG-MVDR 不会凭空分离说话人，需要说话人条件、视觉或语义分离。

## 3. Direction-Preserving MIMO：清理声场但不压扁

[[方向/AI语音/模型/Direction-Preserving MIMO|Direction-Preserving MIMO]] 的目标不是把多通道压成一个“最干净”通道，而是输出增强后的多通道信号，同时保留目标和残余噪声的方向属性、通道间相干性、双耳线索或协方差结构。

这类路线的关键约束是：增强后的声场仍然能被后级模块当成真实多通道观测使用。

典型链路：

```text
multichannel STFT
  -> NN 估噪声协方差 / Cholesky 因子
  -> DP-MWF / MIMO Wiener filtering
  -> enhanced multichannel output
  -> binaural rendering / DOA / post-beamforming / human listening
```

### 3.1. 作为 baseline 的价值

- **保空间 baseline**：助听、AR 透传、空间音频通信、telepresence 等人听任务需要听清，也需要知道声音在哪里。
- **后级空间链路参照**：DOA、SRP、声源跟踪、二级 beamforming、双耳渲染、空间音频编码都能检验增强输出是否仍像真实多通道观测。
- **残留背景约束**：背景噪声完全单声道化会造成定位困难、环境感丢失和听觉疲劳；这可作为生成式 MIMO 的反例测试。
- **多设备 / 多麦参照**：眼镜 + 耳机、会议阵列 + 摄像头、机器人听觉等场景中，保留多通道几何关系比单通道 SNR 更重要。

### 3.2. 优势

- **保留空间线索**：输出仍是多通道，ILD / ITD / inter-channel coherence / DOA 线索不会被 MISO 合成提前丢掉。
- **适合级联系统**：增强输出可以继续喂给 beamformer、定位器或渲染器，而不是只能给 ASR。
- **听感更自然**：不把整个声场挤成目标正前方一个点；残留噪声也保留方向，用户更容易感知环境。
- **经典滤波兜底**：NN 估协方差，DP-MWF 执行保向滤波，避免让网络直接生成所有通道相位。

### 3.3. 局限

- **降噪不一定最狠**：要求残留噪声保方向，就不能随意抹掉空间结构；SNR 和空间保真存在真实冲突。
- **评价口径更复杂**：SI-SDR / PESQ / STOI 只能看一部分，还要看 ILD、ITD、IACC、DOA 偏差、SRP 图和主观定位。
- **设备泛化更难**：HRTF、佩戴位置、麦克风遮挡、通道同步、阵列几何变化都会直接体现为空间漂移。
- **相位错误更刺耳**：MISO 错了可能只是音色差；MIMO 错了会出现双耳不稳、空间晃动、comb filtering。
- **对纯 ASR 不划算**：如果后端只转文字，保留残留噪声空间结构通常不是收益，甚至会留下更多干扰。

## 4. 选择规则

不要先问“哪个模型更先进”，先问输出给谁用。

- **给 ASR / Agent / 转写**：优先 WNG-MVDR；输出单目标流，指标看 WER / CER、目标失真、延迟、WNG 频响。
- **给人耳 / 助听 / AR**：优先 Direction-Preserving MIMO；指标看空间保真、定位稳定、主观听感，不能只看 SI-SDR。
- **同时给人和机器**：分支处理更合理；一路 WNG-MVDR 给 ASR，一路保向 MIMO 给监听/渲染，不要强行用一个输出满足两个目标。
- **强混响远场**：先考虑 [[方向/AI语音/知识/基础概念/WPE（加权预测误差）|WPE]] / MCLP / multi-tap MVDR 等时空处理，再接 WNG-MVDR 或保向 MIMO。
- **小阵列低频**：必须盯 WNG；低频超指向在真实硬件上最容易被自噪声和失配击穿。
- **ad-hoc / 异步多设备**：两类方法都要谨慎；若同步和几何不稳，显式阵列约束可能先失效，需要先解决校准/同步或用更弱几何假设的模型。

## 5. 实验设计不要只比平均分

这类方法的差异主要在失败模式，平均 PESQ / SDR 很容易误导。

应至少分开测这些 case：

- **阵列失配**：麦克风间距、增益、相位、通道顺序、采样同步扰动；看 WNG-MVDR 是否退化为更稳的权重。
- **目标移动**：说话人缓慢移动和突然转头；看 steering / RTF 估计滞后造成的目标挖空。
- **同向干扰**：目标和干扰夹角很小；验证空间自由度边界，而不是只测大角度分离。
- **短窗低延迟**：限制统计窗口后重测 SCM 稳定性；很多离线好结果来自长上下文。
- **低频 + 自噪声**：小阵列低频段单独看 WNG、输出噪声地板和语音变薄。
- **空间保真**：对保向 MIMO 单独看 ILD / ITD / IACC / DOA 偏差和双耳主观定位，而不是只看单通道增强分。

研究判断：WNG-MVDR 的核心风险是“目标被错约束保护或抵消”；保向 MIMO 的核心风险是“听起来干净但空间不稳”。这两个风险不能用同一组指标覆盖，也应成为生成式多通道路线的必测失败模式。

## 6. 实现建议

- **把物理旋钮留出来**：WNG 阈值、diagonal loading、SCM 时间常数、参考通道选择都应可观测；不要完全埋进网络。
- **先做可解释 baseline**：Delay-and-Sum、mask-MVDR、固定 WNG / loading、oracle SCM 是必要对照。
- **训练目标匹配任务**：ASR 前端别为保向牺牲太多抑噪；助听/AR 别用单通道 SI-SDR 逼模型破坏空间线索。
- **保持输出类型清醒**：MISO 不是 MIMO 的简化版，MIMO 也不是“多输出更高级”；它们服务不同下游。
- **真实阵列优先验证**：仿真 RIR、理想同步和精确几何会高估两类方法；上线前必须测真实设备失配。
