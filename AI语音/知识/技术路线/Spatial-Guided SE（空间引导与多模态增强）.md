# Spatial-Guided SE（空间引导与多模态增强）

空间引导 / 多模态在当前预研路线里是 **P3**：它不一定是纯 SE，而更接近 [[方向/AI语音/知识/基础概念/TSE（目标说话人提取）]]、speaker-attributed ASR、diarization-adjacent 前端和语音 Agent 的条件化听觉。价值在于把“增强一段语音”推进到“按人、按方向、按语义条件抽取或生成”。

## 1. 核心问题

多人远场会议里，单纯增强一个参考通道不够。系统真正要回答：谁在说、说了什么、属于哪个人。空间信息和视觉信息可以把“增强”变成“按目标人抽取”。

## 2. 路线拆分

|---|---|---|

| DOA / 方位条件抽取 | [[方向/AI语音/模型/NDSE（双麦定向语音增强）]]、[[方向/AI语音/模型/SSM-NBF（说话人选择神经波束形成）]]、[[方向/AI语音/模型/MC-LExt（起始提示多通道目标说话人提取）]] | 控制增强角宽、训练时选定目标，或以起始提示作身份线索 |

## 3. 预研价值

- **条件化增强**：DOA、目标人位置、视觉目标和语义上下文都可以成为生成式 / 大模型增强的条件，而不是传统前处理标签。
- **speaker attribution 接口**：增强终点不再是单段音频，而是按说话人归属的多路语音 / 文本，直接连接会议理解和语音 Agent。
- **跨模态绑定**：眼镜 / AR / 会议视频提供声源可见性、嘴动和空间方位，适合研究音频-视觉-语言条件如何共同约束输出。
- **重叠说话建模**：空间引导可缓解纯音频分离的跨窗说话人不一致，是多说话人生成式增强的重要条件源。

## 4. 当前难点

- **不是纯 SE**：很多方法的任务是 TSE / diarization / AVSR，不应直接拿 PESQ/STOI 当主指标。
- **DOA 错就全错**：方向估计偏差会同时造成抽取错误和说话人归属错误。
- **近方向多人困难**：两个说话人方向接近时，空间条件不足，需要视觉、说话人 embedding 或语义约束。
- **多模态成本高**：摄像头、同步、ASD、隐私、遮挡都会进入系统复杂度。

## 5. 验证成本

- **输入依赖**：需要稳定 DOA、目标人位置或视觉流。
- **评估复杂**：要看 WER / cpWER / speaker attribution、diarization error、目标泄漏，而不只是增强质量。
- **系统耦合**：VAD、ASD、DOA、TSE、ASR、LLM 后处理互相影响。
- **延迟约束**：智能眼镜 / 助听任务通常比会议转写更严。

## 6. 当前跟踪顺序

1. **先跟 DOA 条件 TSE / PATSE**：把方向作为身份锚点，验证 speaker-attributed WER 和目标泄漏。
2. **再跟 AVSR / SG-TSE / ECHI**：把视觉目标、嘴动和空间线索作为大模型条件源，而不是只看低延迟产品形态。
3. **最后统一指标**：SE、TSE、diarization、speaker-attributed ASR 指标分开记，避免把任务边界混成单一增强分数。

## 7. 关键来源

- [PATSE](https://arxiv.org/abs/2606.29497)：位置感知目标说话人提取，免显式 diarization 的代表。
- [[方向/AI语音/评估/CHiME（语音分离与识别挑战赛）]]：MCoRec、ECHI、SG-TSE 等任务入口。
- [[方向/AI语音/评估/MCoRec（多模态上下文识别）]]：音视频会议识别任务。
