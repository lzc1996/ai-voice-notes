# 音频方案迁移到一维信号

## 1. 核心判断

音频增强里的很多方法本质上是**一维时间序列恢复**，所以可以迁移到 ECG、EEG、工业振动、雷达、地震波、传感器数据等一维信号；但不能把音频专用的声学先验、听感指标和语音语义模块原封不动搬过去。

## 2. 哪些层可迁移

| 层级 | 可迁移内容 | 迁移口径 |
|---|---|---|
| 数学层 | [[方向/AI语音/知识/基础概念/ODE（常微分方程）]]、SDE、[[方向/AI语音/知识/基础概念/Flow Matching（流匹配）]]、扩散 | 都是在状态空间里做连续或随机演化 |
| 架构层 | Transformer、U-Net、DiT、VAE、codec / latent | 换成适合该信号的采样率、窗口和频带 |
| 工程层 | chunking、overlap-add、streaming、latency budget | 长序列通常仍要切块和拼接 |
| 任务层 | denoising、artifact removal、restoration、event detection | VAD 可泛化成 activity / event detection |

## 3. 不能直接搬的部分

- **ASR / 语音语义**：只适用于语音，不适合 ECG、振动或地震波。
- **WavLM / Whisper encoder**：学的是语音结构，不一定适合非语音信号。
- **[[方向/AI语音/知识/基础概念/Spectrogram（声谱图）|mel spectrogram]]**：来自听觉尺度，非音频信号通常要换成小波、频谱、包络谱或领域特征。
- **PESQ / STOI / MOS**：是听感或语音可懂度指标，其他领域要换成诊断、故障、事件或下游任务指标。
- **声学先验**：音高、音素、说话人、混响等概念不能直接泛化。

## 4. 迁移时要重做的东西

- **表示空间**：音频用 STFT / [[方向/AI语音/知识/基础概念/Spectrogram（声谱图）|mel]] / codec latent；ECG 可能用原始波形、小波或心搏切片；工业振动可能用包络谱和转速同步特征。
- **condition**：音频可用 SSL 特征、文本、说话人；医学信号可能用导联、病人 metadata；工业信号可能用转速、负载、传感器位置。
- **损失函数**：不能只追求 MSE 或“更干净”；要保留领域关键事件、峰值、相位、异常形态和下游判定。
- **评估指标**：用领域指标验证，不要用听感指标替代任务正确性。

## 5. 风险

生成式恢复在非语音一维信号里风险更高：ECG 可能生成不存在的异常波形，工业振动可能抹掉故障冲击，地震信号可能生成不存在的事件。原则是：**不能只看“变干净”，必须验证关键事件和下游判断没有被改坏。**

## 6. 信息源迁移

- 音频/语音方法先从 [[方向/AI语音/信息源/语音会议与期刊|语音会议与期刊]]、challenge baseline 和 ESPnet / SpeechBrain recipe 跟踪；迁移到 ECG、EEG、工业振动、雷达或地震时，优先找该领域 benchmark 和 review，不直接套音频排行榜。
- 每次只拿三类材料：一篇综述、一个 baseline 代码、一个 challenge / benchmark 技术报告；先验证数据预处理、窗口、采样率和指标定义能不能替换。
- 经验分享优先看 GitHub issue、官方 baseline 和实验室主页；中文二手材料只作为发现线索，结论要回到论文、代码或 benchmark。

## 7. 相关对象

- [[方向/AI语音/知识/基础概念/Flow Matching（流匹配）|Flow Matching]]：可迁移的生成式速度场范式。
- [[方向/AI语音/知识/基础概念/ODE（常微分方程）|ODE]]：可迁移的连续状态演化工具。
- [[方向/AI语音/知识/基础概念/NAC（神经音频 Codec）|神经音频 Codec]]：一维信号可借鉴 codec / latent 压缩思路，但要换领域表示。
- [[方向/AI语音/知识/基础概念/音频数据预处理|音频数据预处理]]：迁移到非语音信号时，预处理环节也要替换领域特征、切块和 QA 指标。
- [[方向/AI语音/知识/基础概念/VAD（Voice Activity Detection）|VAD]]：可泛化成非语音 activity / event detection。
- [[方向/AI语音/知识/基础概念/SE（语音增强）导论|语音增强导论]]：音频场景里的方法地图。

## 8. 待验证

- 当前目标是否只是音频，还是要扩展到 ECG / EEG / 工业振动 / 雷达 / 地震等非语音一维信号。
- 非语音信号中，哪些事件绝不能被生成式模型改写或抹平。
- 领域指标是否能捕捉“生成得像但事实错”的幻觉风险。
