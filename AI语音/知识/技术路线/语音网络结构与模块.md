# 语音网络结构与模块

## 1. 核心判断

语音模型没有一个“语音专属万能骨干”。真正特殊的是音频信号约束会稳定逼出一组模块：**长序列降采样、时间-频率建模、相位/复数处理、流式因果、条件注入、codec/vocoder 输出**。

因此看语音模型时不要只问“用了 Transformer 还是 U-Net”，更要问：

- 输入是在 waveform、STFT/mel、SSL 表示、codec token，还是 VAE latent 上建模。
- 网络是否显式处理时间-频率二维结构、复数谱和相位。
- 是否要流式，允许多少 lookahead，chunk 边界如何拼回。
- 输出是文字、mask、波形、频谱、codec token，还是 latent。
- 条件来自 [[方向/AI语音/知识/基础概念/SSL 编码器|SSL 编码器]]、文本、说话人 embedding、语义 token，还是退化音频本身。

## 2. 为什么语音结构特殊

| 约束 | 对网络结构的影响 |
|---|---|
| 采样率高、序列长 | 前端卷积降采样、chunking、cache、低帧率 codec / latent 很关键 |
| 语音有多尺度结构 | 短期音素、谐波、瞬态和长期韵律要同时建模 |
| 频谱局部性强 | STFT/mel、2D 卷积、U-Net、[[方向/AI语音/模型/TF-GridNet]]、time-frequency attention 常见 |
| 相位影响听感 | 只预测 magnitude 不够，常见 complex mask、deep filtering、vocoder 或 codec decoder |
| 内容/音色/韵律耦合 | 需要说话人条件、语义条件、SSL 特征或解耦 codec |
| 实时链路严苛 | 因果卷积、流式 attention、VAD、overlap-add、首包延迟都进入模型设计 |

## 3. 常见模块地图

| 模块                            | 做什么                                           | 常见位置                                     |
| ----------------------------- | --------------------------------------------- | ---------------------------------------- |
| Conv / feature extractor      | 从 waveform 提帧级特征并降采样                          | WavLM、Whisper、wav2vec 2.0、ASR encoder 前端 |
| STFT / mel 前端                 | 把波形转成时频表示                                     | ASR、TTS、传统 SE、vocoder 输入                 |
| Mask / mapping head           | 预测时频 mask 或干净谱                                | 判别式语音增强                                  |
| Complex mask / deep filtering | 处理复数谱和局部时频滤波                                  | 低延迟增强、DeepFilterNet 类路线                  |
| [[方向/AI语音/知识/基础概念/Array Audio Signal（阵列音频信号）]] front-end | 利用多通道 [[方向/AI语音/知识/基础概念/IPD（通道间相位差）]]、时延、[[方向/AI语音/知识/基础概念/DOA（到达方向）]] 做 [[方向/AI语音/知识/基础概念/Beamforming（波束形成）]] 和空间增强 | 会议、远场、机器人、语音 Agent 前端 |
| TCN / Conv-TasNet             | 时域卷积建模长上下文                                    | 语音分离、时域增强                                |
| Conformer                     | Transformer 全局注意力 + 卷积局部建模                    | ASR、语音编码器、适配器                            |
| U-Net / [[方向/AI语音/模型/TF-GridNet]]            | 多尺度时频增强和分离                                    | 频域 SE、生成-预测混合系统                          |
| [[方向/大模型/模型结构/DiT（Diffusion Transformer）]] / Transformer backbone    | 在频谱或 latent 上做生成式建模                           | DiT 语音增强、扩散、flow                         |
| Flow / diffusion head         | 预测噪声、score 或速度场                               | Flow Matching、扩散模型                       |
| ODE / SDE sampler             | 多步采样生成目标表示                                    | Flow 用 ODE，扩散常用 SDE/ODE 视角               |
| SSL encoder                   | 提供鲁棒语音条件或评估特征                                 | WavLM、HuBERT、Whisper encoder             |
| [[方向/大模型/基础知识/MTP（Multi-Token Prediction）]] | 并行预测多个后续 token，加速输出侧解码 | ASR、TTS、Omni 语音模型 |
| Codec / VAE encoder-decoder   | 压缩和重建音频                                       | 神经音频 Codec、TTS、codec LM、latent DiT       |
| [[方向/AI语音/知识/基础概念/Vocoder（声码器）]]   | 把 mel、spectrogram、latent 或 token 还原成 waveform | TTS、语音增强、codec LM、表示回归                   |
| VAD / chunker                 | 找语音段、切长音频、控延迟                                 | ASR、长音频增强、语音 Agent                       |

## 4. 任务里的典型组合

### 4.1. ASR

```text
waveform / mel
  -> Conv subsampling
  -> Transformer / Conformer / Whisper-like encoder
  -> CTC / Transducer / attention decoder / LLM decoder
  -> text + timestamp
```

ASR 的特殊点是输出文字，语音细节只要足够支撑识别即可。[[方向/AI语音/知识/基础概念/CTC（连接时序分类）|CTC]]、Transducer、attention decoder 和 LLM decoder 是常见输出层/解码路线。因此 Whisper、Qwen3-ASR、Seed-ASR 这类模型会更重视语义鲁棒、长音频稳定、时间戳、热词和语言建模，而不是高保真波形重建。

### 4.2. 语音增强

```text
noisy waveform / STFT / latent
  -> 判别式分支：mask / mapping / TF-GridNet
  -> 生成式分支：DiT / diffusion / Flow Matching
  -> vocoder / codec decoder / overlap-add
  -> enhanced waveform
```

语音增强的特殊点是输出仍是语音波形，不能只“听起来像”，还要内容、说话人和时间结构不被改写。当前强路线通常是判别式守内容、生成式补听感，例如 [[方向/AI语音/模型/GAP-URGENet|GAP-URGENet]]。

### 4.3. TTS / 声音克隆

```text
text / phoneme / prompt audio
  -> semantic / prosody / speaker condition
  -> acoustic model / codec LM / flow model
  -> codec decoder / vocoder
  -> generated waveform
```

TTS 的特殊点是条件控制更强：文本决定内容，说话人 embedding 或 prompt audio 决定音色，prosody/style token 决定表达。codec token 可以接 LLM，但 decoder 上限会锁住最终音质。

### 4.4. 音频 LLM / 语音 Agent

```text
audio
  -> Whisper / WavLM / Qwen audio encoder
  -> projector / Q-Former / Conformer adapter
  -> LLM
  -> text response or speech token response
```

这里的核心模块是“音频表示到 LLM token 空间的适配器”。它适合理解和对话，但如果任务是高保真增强或恢复，仍要另接 codec / vocoder / flow 这类生成头。

## 5. 容易混淆的点

- **[[方向/AI语音/知识/基础概念/Flow Matching（流匹配）|Flow Matching]] 不是网络结构**：它是训练目标和采样范式，骨干可以是 DiT、U-Net 或其他 Transformer。
- **[[方向/AI语音/知识/基础概念/ODE（常微分方程）|ODE]] 不是声波模型**：它只是推理时沿速度场积分的数值工具。
- **[[方向/AI语音/知识/基础概念/SSL 编码器|SSL 编码器]] 不是 codec**：WavLM/Whisper encoder 输出特征，不能直接解码成高保真音频。
- **codec token 不是文本 token**：它服务重建和生成，长度、码本、帧率和 decoder 质量决定音频上限。
- **[[方向/AI语音/知识/基础概念/Vocoder（声码器）|Vocoder]] 不是完整 codec**：vocoder 负责表示到波形，codec 还包含把波形压成表示的 encoder。
- **[[方向/大模型/基础知识/MTP（Multi-Token Prediction）|MTP]] 不是音频 tokenizer**：它是 token 解码器上的多步预测头，解决输出速度，不负责把音频编码成 token。
- **音频方案不能原封不动迁移到所有一维信号**：数学范式和架构层可迁移，但表示、condition、损失和评估必须换领域版本，见 [[方向/AI语音/知识/技术路线/音频方案迁移到一维信号|音频方案迁移到一维信号]]。

## 6. 选型速查

| 目标 | 优先模块 |
|---|---|
| 低延迟通话增强 | causal Conv / deep filtering / [[方向/AI语音/模型/TF-GridNet]] / VAD / overlap-add |
| 离线高保真修复 | DiT / diffusion / Flow Matching + codec/VAE latent + vocoder |
| 低幻觉语音增强 | 判别式分支、SSL 表示回归、混合式融合、CAcc/SpkSim 检查 |
| ASR 稳定转写 | Conformer / Whisper-like encoder、VAD、分段、语言模型解码 |
| 接 LLM 生态 | SSL/ASR encoder + adapter，或 codec token + decoder-only LM |
| 长音频处理 | VAD、fixed chunk、overlap context、cache、crossfade / overlap-add |

## 7. 相关对象

- [[方向/AI语音/知识/基础概念/SE（语音增强）导论|语音增强导论]]：增强任务和方法谱系入口。
- [[方向/AI语音/知识/基础概念/Array Audio Signal（阵列音频信号）|阵列音频信号]]：多通道输入、阵列增强和音频大模型后端的分工。
- [[方向/AI语音/知识/生成式语音增强/DiT 与语音增强（DiT-based Speech Enhancement）|DiT 与语音增强]]：生成式语音增强的 Transformer 骨干路线。
- [[方向/AI语音/知识/基础概念/Flow Matching（流匹配）|Flow Matching]]：速度场训练和 ODE 采样范式。
- [[方向/AI语音/知识/基础概念/SSL 编码器|SSL 编码器]]：WavLM、HuBERT、Whisper encoder 等条件/表示模块。
- [[方向/大模型/基础知识/MTP（Multi-Token Prediction）|MTP]]：输出侧多 token 预测和解码加速模块。
- [[方向/AI语音/知识/基础概念/NAC（神经音频 Codec）|神经音频 Codec]]：codec token、latent 和 decoder/vocoder 上限。
- [[方向/AI语音/知识/基础概念/Vocoder（声码器）|声码器]]：把 mel、spectrogram、latent 或 token 还原成 waveform 的输出侧模块。
- [[方向/AI语音/知识/基础概念/VAD（Voice Activity Detection）|VAD]]：长音频切分和实时端点检测模块。
- [[方向/AI语音/MOC - ASR|ASR]]：识别任务的 encoder-decoder / [[方向/AI语音/知识/基础概念/CTC（连接时序分类）|CTC]] / streaming 工程入口。

## 8. 待验证

- 当前目标链路优先做 ASR、语音增强、TTS，还是语音 Agent；不同任务的“最佳模块”不是同一套。
- 中文、方言、混响、漏音样本中，Whisper encoder、WavLM 和 Conformer encoder 哪个更适合作为条件特征。
- 长音频 chunk 边界、相位连续性和说话人保持是否需要单独做测试集。
