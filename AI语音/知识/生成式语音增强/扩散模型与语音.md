# 扩散模型与语音

扩散模型在语音领域的角色可以一句话概括：**它把"[[方向/AI语音/知识/基础概念/SR（语音恢复）|语音恢复]]/生成"从回归问题变成了生成问题，从而定义了音质上限——然后因为自己的速度短板，把这个角色移交给了它的简化版 [[方向/AI语音/知识/基础概念/Flow Matching（流匹配）|flow matching]]**。本笔记从扩散本身的视角串起 vocoder、TTS、语音增强、音频生成四条线。

## 1. 它解决了判别式解决不了的问题

判别式 SE（掩码/回归）学的是"给定带噪输入，输出干净语音的条件均值"。强退化时干净语音本质是**一对多**的——同一段烂音频对应多种合理干净版本，回归模型只能输出平均，结果就是"干净但发闷"。

扩散模型换个问法：不预测均值，而是学习干净语音的整个条件分布，通过迭代去噪从中**采样**出一个具体样本。丢掉的谐波、被噪声淹没的细节可以"合理地脑补"出来——音质上限就此改写，代价是幻觉（见 [[语音增强评估指标体系]]）。

## 2. 在语音增强中的角色谱系

| 阶段 | 代表 | 扩散扮演的角色 |
|------|------|---------------|
| 开创（2022） | **[[方向/AI语音/模型/SGMSE+]]** | 首次证明 score-based 扩散可做 SE：复数谱域 SDE 去噪，质量超判别式 |
| 混合（2023） | **[[方向/AI语音/模型/StoRM]]** | 退居"残差生成器"：判别式预测主干，扩散补其漏掉的细节——生成+预测混合的早期形态 |
| 巅峰（2025） | **DiTSE** | 潜空间扩散 + DiT 骨干，QMOS 4.34 与录音室音频不可区分——SE 音质天花板（见 [[DiT 与语音增强（DiT-based Speech Enhancement）]]） |
| 让位（2025–） | FlowSE / [[方向/AI语音/模型/DiT-Flow]] / Stream.FM | SDE 随机采样需几十步，实时性不过关；[[方向/AI语音/知识/基础概念/Flow Matching（流匹配）]] 用确定性 ODE 直线传输把步数砍到 5–20 步——**扩散的生成思想被继承，扩散本身被替换** |

## 3. 不止增强：扩散在整个语音/音频里的角色

- **声码器**：DiffWave、WaveGrad——最早的语音扩散应用，迭代去噪把 mel 谱变波形
- **TTS**：NaturalSpeech 系、F5-TTS（FM 版）——合成自然度的跃升主要靠扩散/FM
- **通用音频生成**：AudioLDM、Stable Audio——潜空间扩散（LDM 范式）从图像借到音频
- **声学仿真**：Gencho 等用扩散生成 RIR——训练数据的原料也开始由扩散造（见 [[Reverberation Modeling（混响建模）]]）
- **带宽扩展 / 丢包修复**：AudioSR、NU-Wave 系

共同逻辑：**凡是"输出是连续音频、且答案不唯一"的任务，扩散都是自然的建模工具**。

## 4. 当前定位（2026 视角）

- **历史贡献**：确立"生成式语音"范式、证明采样质量碾压回归均值、把 [[方向/大模型/模型结构/DiT（Diffusion Transformer）|DiT]] / 潜空间 / LDM 工具链带进语音社区。
- **现实处境**：纯 SDE 扩散在增强任务上已鲜有新工作——FM 在数学上是它的"直线化"特例，训练更稳、采样快一个量级；增量几乎全在 FM 一侧。
- **存续形态**：以"生成+预测混合"活在 SOTA 系统里（StoRM 思想 → [[方向/AI语音/模型/GAP-URGENet|GAP-URGENet]] 融合架构），以及作为 FM 论文的标准基线（DiT-Flow 的所有对比都打 SGMSE/StoRM）。

一句话：**扩散是语音生成时代的奠基者，flow matching 是它的继任者，混合架构是它思想的最终归宿**——角色从"主角"变成"范式和上限的定义者"。
