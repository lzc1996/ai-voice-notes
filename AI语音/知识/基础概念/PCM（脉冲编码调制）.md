# PCM（脉冲编码调制）

## 1. 身份

脉冲编码调制（Pulse-Code Modulation, PCM）是将连续信号变成数字样本序列的一类表示与编码方法。音频场景中，它描述采样值如何被量化并编码；PCM 本身不指定唯一的采样率、位深、声道数、整数/浮点表示或文件容器。

## 2. 核心机制

```text
连续音频 -> 抗混叠滤波 -> 等间隔采样 -> 量化幅度 -> 编码为数字样本
```

- **采样**把连续时间信号变为离散时间序列；采样率决定每秒记录多少个样本。
- **量化**把样本幅度映射到有限表示级别；位深与量化格式决定可表示的精度和范围。
- **编码**把量化值表示成比特序列；常见音频 PCM 可用有符号整数或浮点样本格式。

这些是概念上的处理步骤；具体系统可能将滤波、量化和编码融合实现。有限位深量化会引入量化误差，采样也不能恢复采样前已被滤除或超过可表示带宽的信息。

## 3. 与常见格式的边界

- **PCM 与 PCM16**：PCM 是方法/表示类别；[[方向/AI语音/知识/基础概念/PCM16（16-bit Pulse Code Modulation）]] 是以 16 位整数保存每个样本的一种具体格式。
- **PCM 与采样率**：`16 kHz` 描述每秒采样次数，不代表 16-bit PCM。
- **PCM 与容器**：WAV 是可包含 PCM 音频数据的容器；裸 PCM 字节流通常需要外部元数据说明采样率、声道数、样本格式和端序。
- **PCM 与压缩编码**：未压缩 PCM 通常直接保存每个量化样本；G.711 等电话语音编码采用 PCM 相关的非均匀量化编码，不能简单等同于线性 PCM16。

## 4. 为什么重要

PCM 是录音、音频文件交换、语音 API 输入输出以及模型波形预处理中的常见数字音频表示。实际接入时必须同时确认采样率、声道数、位深/样本格式、端序和容器；只写“PCM”不足以保证两端按同一种字节布局解释音频。

## 6. 关键来源

- [ITU-T Recommendation G.711: Pulse code modulation (PCM) of voice frequencies](https://www.itu.int/rec/T-REC-G.711/en)
  - 内容定位：语音频带 PCM 编码标准实例，展示 PCM 与特定编码规则的关系。
  - 用途：区分一般 PCM 表示与具体电话语音编码。
- [Microsoft WAVEFORMATEX structure](https://learn.microsoft.com/en-us/windows/win32/api/mmreg/ns-mmreg-waveformatex)
  - 内容定位：WAVE 格式字段分别描述采样率、声道、位深及块对齐等属性。
  - 用途：说明 PCM 数据格式需要与采样参数和容器元数据共同解释。

## 7. 待验证

- 项目接口中 `PCM` 是否明确指线性整数 PCM，还是也接受 G.711 等 companded 编码。
