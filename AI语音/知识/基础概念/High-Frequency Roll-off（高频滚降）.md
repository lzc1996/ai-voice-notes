# High-Frequency Roll-off（高频滚降）

## 1. 身份

`High-Frequency Roll-off`（高频滚降）是频响或频谱能量在高频区域逐渐下降的现象。它不是“高频突然被切掉”，而是从某个频段开始，能量随频率升高逐步变弱。

边界：高频滚降是一种客观频谱 / 频响趋势；“闷”“不亮”“隔着布”是对应的主观听感。严重的低通滤波、高频截断、麦克风遮挡、codec 带宽限制和过度降噪都可能造成高频滚降。

## 2. 直觉

```text
原始语音高频细节：齿音、擦音、气声、空气感、清晰度边缘
处理链路：麦克风 / codec / 低通 / 降噪 / 声码器
输出结果：高频能量逐渐变弱 -> 听起来更闷、更远、更不通透
```

语音里很多清晰度线索集中在中高频和高频区域，尤其是 `s / sh / f / t / k` 这类辅音的瞬态和摩擦噪声。高频滚降轻微时只是“不够亮”，严重时会影响可懂度和说话人音色。

## 3. 在语音增强里的含义

- 降噪模型可能把高频噪声和语音高频细节一起抹掉，导致背景更干净但人声发闷。
- 频谱掩码过平滑或过强时，[[方向/AI语音/知识/基础概念/Spectral Envelope（频谱包络）]] 的高频外形会被压低。
- 声码器 / codec 重建不足时，高频细节可能变少，进一步带来音色染色。
- 评价上可能出现 `DNSMOS / OVRL_MOS` 不低、`NISQA Coloration` 偏低：噪声减少了，但音色自然度下降。

## 4. 如何诊断

- **听 A/B**：重点听齿音、擦音、气声、尾音和空间开阔感是否被抹掉。
- **看声谱图**：比较 enhanced 与 clean / noisy 的高频区域能量是否整体变暗或变窄。
- **看长期平均频谱**：对同一批样本画 LTAS 或平均 log spectrum，观察高频斜率是否比参考更陡。
- **做受控 EQ**：轻微补高频或降低低中频后，如果清晰度明显回来，说明问题可能是频响偏暗。
- **结合指标残差**：`NISQA Coloration` 低、`Noisiness` 高时，常见解释是“很干净但偏闷 / 高频细节不足”。

## 5. 容易混淆

- **低通滤波**：处理方式；高频滚降是结果。低通可以造成平滑滚降，也可以造成硬截断。
- **高频截断**：比滚降更突兀，像某个 cutoff 以上直接没有能量。
- **闷**：主观听感；高频滚降是常见物理原因之一。
- **[[方向/AI语音/知识/基础概念/Boxy Sound（箱音）]]**：箱音通常还带低中频腔体感；高频滚降只解释“不亮 / 不通透”的一部分。
- **响度不足**：整体音量小；高频滚降可以在整体响度正常时仍然存在。

## 6. 相关对象

- [[方向/AI语音/评估/NISQA]]：`Coloration` 子维度可作为高频滚降导致音色染色的弱诊断信号。
- [[方向/AI语音/评估/OVRL_MOS]]：总体质量分可能被降噪干净度拉高，不能单独解释高频细节损失。
- [[方向/AI语音/知识/基础概念/Microphone Channel Modeling（麦克风信道建模）]]：麦克风/设备频响中的高频倾斜、低通滚降和幅度下限都可能造成高频滚降。
- [[方向/AI语音/知识/基础概念/Spectrogram（声谱图）]]：可直接观察高频能量是否衰减。
- [[方向/AI语音/知识/基础概念/Spectral Envelope（频谱包络）]]：高频滚降体现为谱包络高频端下倾。
- [[方向/AI语音/知识/基础概念/Formant（共振峰）]]：高频细节和高阶共振结构受损会影响音色自然度。
- [[方向/AI语音/知识/基础概念/SE（语音增强）导论]]：高频滚降是增强输出听感质量诊断中的一种故障标签。
