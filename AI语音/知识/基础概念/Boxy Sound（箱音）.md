# Boxy Sound（箱音）

## 1. 身份

`Boxy Sound`（箱音）是一种音色染色：语音内容通常仍可懂，但听起来像被关在纸箱、柜体、小房间或小音箱里，空间感窄、低中频闷胀，高频开阔感不足，常伴随 [[方向/AI语音/知识/基础概念/High-Frequency Roll-off（高频滚降）]]。

边界：箱音不是单纯底噪。底噪更接近 [[方向/AI语音/评估/NISQA]] 的 `Noisiness`；箱音更接近 `Coloration`。它也不等同于响度过大或过小，而是频谱包络、共振结构或回放链路频响偏移造成的主观音色问题。

## 2. 直觉

```text
正常近讲语音 -> 低中频共振 / 频响偏置 / 算法过处理 -> 频谱包络被染色 -> 听起来闷、窄、像在盒子里
```

箱音经常出现在低中频局部能量突出、低频衰减不足、高频空气感缺失，或某个腔体 / 房间响应被增强的时候。工程排查时可先盯 `150-500 Hz` 左右的低中频堆积，但不要把这个范围当硬阈值；不同说话人、麦克风、房间和算法会让问题频段移动。

## 3. 在语音增强里的含义

- 过度降噪后，背景变干净，但语音的 [[方向/AI语音/知识/基础概念/Spectral Envelope（频谱包络）]] 被过平滑或窄带化。
- dereverberation / beamforming 可能保留了直达声，却引入房间残留或频响凹凸。
- neural vocoder / codec 后处理可能让 [[方向/AI语音/知识/基础概念/Formant（共振峰）]] 和高频细节不自然。
- 评价上可能出现 `DNSMOS / OVRL_MOS` 高、`NISQA Coloration` 低：噪声少，但音色不自然。

## 4. 如何诊断

- **先听 A/B**：对比 noisy / enhanced / clean 或 near-field，判断增强后是否更像“盒子里”。
- **看声谱图**：检查低中频是否堆积、高频是否异常衰减、元音稳定段是否变窄或变闷。
- **看频谱包络**：比较增强前后 formant 周围和 `2-4 kHz` 清晰度频段是否被削弱或抹平。
- **看指标残差**：`NISQA Coloration` 明显低于 MOS / Noisiness 时，优先怀疑音色染色；若 `Discontinuity` 也低，可能是断续 / 门控同时存在。
- **做受控 EQ**：临时削减低中频或补一点高频，如果箱音明显缓解，说明问题更可能是频响 / 包络，而不是内容错误。

## 5. 容易混淆

- **闷**：更偏高频不足；箱音通常还带低中频腔体感。
- **鼻音**：更偏鼻腔 / 中高频共振异常，像捏鼻子或鼻腔堵塞。
- **金属音**：更偏神经网络伪影、音乐噪声或相位 / 细节闪烁。
- **混响**：更偏空间尾音和反射；箱音可以由小空间混响导致，但主观重点是腔体染色。
- **电话音**：更偏带宽受限；箱音可以像电话音，但低中频盒状共振更突出。

## 6. 相关对象

- [[方向/AI语音/评估/NISQA]]：`Coloration` 子维度可作为箱音 / 音染的弱诊断信号。
- [[方向/AI语音/评估/OVRL_MOS]]：DNSMOS / P.835 overall 可能被降噪干净度拉高，不能单独解释箱音。
- [[方向/AI语音/知识/基础概念/Spectral Envelope（频谱包络）]]：箱音常表现为频谱包络形状异常。
- [[方向/AI语音/知识/基础概念/Formant（共振峰）]]：共振峰和声道滤波线索被改变时，箱音或其他音染更明显。
- [[方向/AI语音/知识/基础概念/Spectrogram（声谱图）]]：初筛箱音时可看频段堆积和高频衰减。
- [[方向/AI语音/知识/基础概念/High-Frequency Roll-off（高频滚降）]]：箱音经常伴随高频细节和空气感不足。
- [[方向/AI语音/知识/基础概念/SE（语音增强）导论]]：箱音是增强输出听感质量诊断中的一种故障标签。
