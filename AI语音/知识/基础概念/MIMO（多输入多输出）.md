# MIMO（多输入多输出）

## 1. 身份

`MIMO`（Multi-Input Multi-Output，多输入多输出）是多通道语音处理里的**系统维度分类**：输入 $M$ 个麦克风通道、输出 $N \ge 2$ 个通道（或每目标一条流）的处理形态。对照 **MISO**（Multi-Input Single-Output，多入单出）——经典增强 / 波束形成把多通道压成单通道（[[方向/AI语音/知识/基础概念/MVDR（最小方差无失真响应）|MVDR]]、mask-based SE、多数 beamformer 都是 MISO）。

边界：MIMO 是**输入/输出维度**的刻画，不等于"空间保真"也不等于"分离"——可以是保向输出（保留 ITD/ILD），也可以是多目标流输出（每说话人一条）；注意与无线通信的 MIMO（多天线空分复用）语境区分。

## 2. 分类谱系

| 形态       | 输入 → 输出      | 代表                                                |                                    |
| -------- | ------------ | ------------------------------------------------- | ---------------------------------- |
| SISO     | 单 → 单        | 传统单通道增强（掩码 / 谱映射）                                 |                                    |
| MISO     | 多 → 单        | MVDR / GSC / mask-based beamformer、多数神经增强         |                                    |
| MIMO（保向） | 多 → 多（含空间线索） | [[方向/AI语音/模型/Direction-Preserving MIMO]]、双耳助听处理 |
| MIMO（多流） | 多 → 每目标一条    | ECHI 类多说话人增强（每对话伙伴一条流）、[[方向/AI语音/知识/基础概念/SS（语音分离）]] 输出                            |
| MIMO（生成） | 多 → 多（联合生成）  | [[方向/AI语音/模型/mSGMSE]]（通道相关性由联合分布保证）             |

## 3. 为什么重要

- **空间线索不塌缩**：MISO 输出单通道时 [[方向/AI语音/知识/基础概念/ILD（双耳声级差）|ILD]] / [[方向/AI语音/知识/基础概念/IPD（通道间相位差）|IPD]] 信息丢失；MIMO 保向输出服务双耳渲染、DOA、telepresence 等下游（见 [[方向/AI语音/模型/Direction-Preserving MIMO|保向 MIMO]] 的动机）。
- **多目标并行**：多人场景（会议、助听）需要每人一条流，MIMO 是任务的自然形态（CHiME-9 ECHI 每场 3 条增强流）。
- **联合生成保相关性**：逐通道独立生成会破坏通道间协调；MIMO 联合生成（mSGMSE）由分布结构保证空间一致性。
- **代价**：输出自由度上升 → 目标函数（保真 + 空间保真）与评测口径（含空间指标）都更复杂。

## 4. 相关对象

- [[方向/AI语音/模型/Direction-Preserving MIMO|Direction-Preserving MIMO]]：保向 MIMO 的代表（全盲、输出含方向线索）。
- [[方向/AI语音/模型/mSGMSE|mSGMSE]]：MIMO 扩散增强（联合生成所有通道）。
- [[方向/AI语音/评估/ECHI（助听对话增强）|ECHI]]：多流 MIMO 任务的评测基准（3 条输出流）。
- [[方向/AI语音/知识/基础概念/ILD（双耳声级差）|ILD]] / [[方向/AI语音/知识/基础概念/IPD（通道间相位差）|IPD]]：MIMO 保向输出要保留的空间线索。
- [[方向/AI语音/知识/基础概念/SS（语音分离）|SS]] / [[方向/AI语音/知识/基础概念/TSE（目标说话人提取）|TSE]]：多目标输出的相邻任务。
