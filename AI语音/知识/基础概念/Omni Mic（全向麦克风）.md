# Omni Mic（全向麦克风）

## 0. 背景

**1) 指向性问题出现前**：最早的实用麦克风（碳精式、电容压力式）只响应声压，本身没有"指向性"这个概念——全向不是刻意设计出的模式，而是"后腔封闭、只测声压"这一换能方式的默认结果。声压像气压一样作用于各个方向，所以压力式麦克风天生对朝向不敏感。

**2) 转折点**：1930 年代扩声与电影录音要抑制环境声和返送啸叫，工程师的手法是**把压力式单元与压差式（8 字形）单元按比例电混合**，得到心形（cardioid）。Shure 的 Ben Bauer 于 1937 年做出首个单振膜 cardioid（Unidyne）；在此之前，单向响应的通行做法就是"全向单元 + 双向单元混合"（Shure 官方口径）。所以指向性的历史顺序是：**全向（零阶）→ 与 8 字混合出心形族 → 单振膜直接实现**。

**3) 之后发生了什么**：
- **测量与记录领域保留全向作为基准**：声级计、声压测量必须全向，否则读数依赖入射角；Ambisonics 把全向当作 0 阶分量 W（Gerzon 1973，见 [[方向/AI语音/知识/基础概念/B-format（一阶 Ambisonics）|B-format]]）。
- **器件小型化反转了工程范式**：MEMS 电容麦天生全向，晶圆级工艺让灵敏度/频响一致性远优于分立单元，于是"**全向单元 + 阵列后处理**"取代"单振膜物理指向"成为消费电子的默认方案——ADI/InvenSense 的应用笔记明确"所有 MEMS 麦克风都是全向，指向性由后续波束形成决定"。
- **代价在近十年被重新发现**：真实"全向"只在膜片尺寸远小于半波长时成立，高频会自发变指向。而阵列语音增强的模型几乎全部假设单元理想全向（[[方向/AI语音/模型/SFB-NSE|SFB-NSE]] 的 UCA 观测模型、[[方向/AI语音/评估/REVERB Challenge（混响语音挑战）|REVERB]] 的 8 麦圆阵、[[方向/AI语音/模型/PhaseCoder|PhaseCoder]] 的"自由悬浮全向麦"假设），这条"理想-器件"差距就成了模型误差的一个隐藏来源。

## 1. 身份

`Omni Mic`（全向麦克风 / 全指向麦克风）是**灵敏度对入射方向不敏感**的麦克风：在消声环境中绕麦克风 360° 移动声源，输出电平近似恒定，极坐标图接近圆（三维为球），拾音角 360°，指向性指数 DI = 0 dB。

在一阶指向性的统一表达式里，全向是 $B=0$ 的退化端点：

$$
\rho(\theta) = A + B\cos\theta,\qquad (A,B)=(1,0)
$$

其中 $\rho$ 是归一化到 0° 的灵敏度，$\theta$ 为相对"正面"的入射角。

边界（四条都必须区分开）：
- **不是"没有空间信息"**：单只全向麦的输出确实不含方向，但方向可由多只全向麦之间的时延/相位/幅度差恢复——这正是 [[方向/AI语音/知识/基础概念/Beamforming（波束形成）|波束形成]] 与 DOA 的物理基础。
- **不是"不抑制噪声"**：全向**单元**没有指向性抑制能力，但由它组成的阵列系统可以做出很强的指向性。
- **不是会议场景的"全向麦"设备**：桌面全向麦是环形阵列 + 波束合成出的 360° 拾音，其物理单元仍是全向 MEMS（见 §6）。
- **不等于 B-format 的 W 通道**：W 是 0 阶全向分量，但带约定缩放（FuMa 下 $1/\sqrt{2}$），不能直接当普通全向麦用。

## 2. 在一阶指向性族里的位置

一阶指向性族是压力分量与压差分量的线性组合，$(A,B)$ 的取值决定模式（系数取 DPA 官方口径，拾音角与零点角度取 Shure 口径）：

| 模式 | $\rho=A+B\cos\theta$ | 拾音角 | 最不敏感角度 | 相对全向的环境声 |
|---|---|---|---|---|
| 全向 omni | $1+0\cos\theta$ | 360° | 无零点 | 基准（最高） |
| 亚心形 subcardioid | $0.7+0.3\cos\theta$ | 宽 | 后向 −3…−10 dB | 略低 |
| 心形 cardioid | $0.5+0.5\cos\theta$ | 131° | 180° | 约为全向的 1/3（降低约 2/3） |
| 超心形 supercardioid | $0.37+0.63\cos\theta$ | 115° | 125° | 更低 |
| 超指向 hypercardioid | $0.25+0.75\cos\theta$ | 105° | 110° | 最低 |
| 8 字 bidirectional | $0+\cos\theta$ | — | 90° / 270° | 侧向全抑制 |

两点常被忽略：
- **DI 最大的是 hypercardioid（标准口径约 6 dB），不是 cardioid（约 4.8 dB）**；全向是这一族唯一 DI = 0 的成员，因此它也是"阵列增益 = 纯阵因子"的参照点。
- **全向是唯一没有邻近效应（proximity effect）的模式**。邻近效应来自压差分量，全向只有压力分量，近讲不抬低频——这也是全向麦在声学测量、声级计中不可替代的原因之一。

## 3. 怎么造出来

- **压力式（后腔封闭）**：膜片只感受声压，对朝向不敏感 → 天然全向；代价是无邻近效应、无方向抑制、易收环境声与反馈。
- **压差式（后腔开孔 / 声阻网络）**：响应声压梯度（偶极子）→ 8 字，有邻近效应。
- **混合式**：$A\cdot$压力 $+\ B\cdot$梯度，电路混合或声学网络实现 → cardioid 族全部成员。
- **MEMS 电容式**：结构与压力式同源，因此**全部 MEMS 麦都是全向**（ADI、InvenSense、Same Sky 的应用笔记一致口径）；晶圆级工艺带来的灵敏度/频响一致性是"多只全向麦组阵列"能成立的前提——阵列的零点深度直接取决于单元失配。
- **阵列合成**：指向性完全由后处理决定，同一组全向单元可用不同权重产出不同指向性的通道，"单元是否全向"因此不再重要——只要能保证单元响应已知且与角度无关。

## 4. 器件级非理想：全向只在低频成立

理想全向要求膜片与壳体尺寸远小于波长（$ka \ll 1$）。一旦膜片直径接近半波长，两个机制同时启动：

1. **压力平均（孔径效应）**：斜入射时膜片各点看到的声压相位不同，输出是表面压力的平均值，高频被抵消；
2. **衍射遮挡**：麦克风本体在后方形成声影，后向高频衰减。

**膜片直径与压力平均起始频率**（Williams 手册口径，衰减约 3–5 dB 处）：

| 膜片直径 | 起始频率 |
|---|---|
| 6.35 mm（1/4"） | 约 26.8 kHz |
| 12.7 mm（1/2"） | 约 13.4 kHz |
| 15 mm | 约 11 kHz |
| 19 mm（3/4"） | 约 9 kHz |
| 25.4 mm（1"） | 约 6.8 kHz |

**实测口径**（Brüel & Kjær 1996，经语音测量选麦教程转述）：0.5 英寸膜片在 10 kHz、70° 入射约 −3 dB，20 kHz 约 −7 dB；1 英寸膜片的同类效应频率减半（5 / 10 kHz）；1 英寸头的"全向"实际上限约 5 kHz。

还有一条反方向偏差：麦克风本体的存在会改变局部声阻抗，**正对方向的高频会被抬升**。厂家常用 EQ 压平轴上响应，结果是"离轴反而滚降"——于是真实的"全向麦"有两个频响（轴上 / 离轴），而不是一个。对 48 kHz 全带录音、或大振膜测量麦，这一点会直接污染"单元响应与角度无关"的假设；对 16 kHz 采样的常见 MEMS（孔径毫米级），语音带宽内基本可视为全向，但这是量级判断，不是免责条款。

## 5. 在阵列语音增强里的地位

阵列信号模型的默认写法是

$$
y_m(t)=\sum_k h_{mk}(t)*s_k(t)+n_m(t),\qquad
\mathbf{a}(\omega,\theta)=\big[e^{-j\omega\tau_1(\theta)},\dots,e^{-j\omega\tau_M(\theta)}\big]^\top
$$

注意导向矢量里**只有几何相位**，没有单元响应项——这等价于默认 $a_m(\omega,\theta)\equiv 1$，即所有单元理想全向。行业资料对此说得很直白：上述推导"只在所有麦克风都完美全向时才能实现"；若单元有指向性，需把 $\alpha_m(\omega,\theta)$ 乘进每个阵元流形。

这一假设撑起四条推论：

1. **可分离性**：阵列指向性 = 阵因子 × 单元指向性。单元全向时阵因子单独决定波束，MVDR / MPDR / 超指向等闭式权重设计才成立。
2. **校准变简单**：只需校幅度、相位、时延，不必逐麦逐角度存指向性表；[[方向/AI语音/知识/基础概念/Microphone Channel Modeling（麦克风信道建模）|麦克风信道建模]] 里 $h_{mic}$ 因此可以退化成"与角度无关的标量频响"。
3. **扩散场相干函数成立**：[[方向/AI语音/知识/基础概念/扩散声场（Diffuse Sound Field）|扩散声场]] 下通道间相干性 $\Gamma_{ij}=\mathrm{sinc}(\omega d_{ij}/c)$ 的前提就是单元无指向性；单元一旦定向，噪声场统计随之改变，SCM 估计与掩码类方法的前提一起动摇。
4. **相位干净**：全向单元没有"离轴染色"这种角度相关频响，通道间相位只反映传播时延，[[方向/AI语音/知识/基础概念/IPD（通道间相位差）|IPD]] / [[方向/AI语音/知识/基础概念/ITD（耳间时间差）|ITD]] 类空间特征才可靠。

代价也很清楚：
- **单麦 SNR 最差**：不靠指向性抑制环境声，心形麦收到的环境声约为全向的 1/3。
- **易反馈、易收混响**：全向麦在扩声场景几乎不可用。
- **指向性只能靠孔径换**：小设备低频指向性不足，这是 [[方向/AI语音/知识/基础概念/Array Aperture（阵列孔径）|阵列孔径]] 的硬约束，不能靠单元解决。

**反过来，指向性单元进阵列的代价**：每只麦带一个角度相关、且彼此失配的频响，破坏 §5 的可分离性与相干性假设，校准成本陡增——这就是为什么阵列语音增强文献（REVERB 的 8 麦圆阵、SFB-NSE 的 UCA、PhaseCoder 的自由悬浮假设）几乎统一采用全向单元。[[方向/AI语音/知识/基础概念/Neural-VME（神经虚拟麦克风估计）|Neural-VME]] 估计出的虚拟麦克风是"信号"而非器件，其等价单元响应由训练数据隐含——用全向阵列采集的数据训出来的 VM，也隐含全向假设。

## 6. 常见误判

- **"全向 = 没有方向信息"**：单通道成立，多通道不成立。全向阵列的方向信息全在通道间时延/相位里，反而是最干净的载体。
- **"全向 = 不能降噪"**：把单元指向性和系统指向性混为一谈。会议全向麦、智能音箱都是全向单元 + 波束形成。
- **"全向麦产品 = 单只全向单元"**：桌面"全向麦"（如思必驰 M6/M12 一类）是环形阵列合成 360° 拾音，物理单元是全向 MEMS，功能上更接近"全向波束"而非"全向单元"。
- **"B-format 的 W 就是全向麦"**：W 是 0 阶球谐分量，FuMa 约定下带 $1/\sqrt{2}$ 缩放，单独使用丢失全部方向信息；且 B-format 的方向来自 W/X/Y/Z 的联合。
- **"全向麦在全频段都全向"**：只在 $ka\ll1$ 成立，见 §4 的频率表。
- **"全向麦有邻近效应"**：邻近效应来自压差分量，全向麦没有；近讲不抬低频。
- **"全向麦噪声大是因为它全向"**：小膜片 MEMS 自噪声高是尺寸-灵敏度权衡的结果，与指向性无关。
