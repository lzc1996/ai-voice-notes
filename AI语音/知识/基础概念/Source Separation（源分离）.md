# Source Separation（源分离）

## 1. 身份

`Source Separation`（源分离）是上位概念：给一段混合音频，估计出组成它的各个「源」，每个源输出一路独立音频。最小形式化是 `mixture -> source_1, source_2, ..., source_n`。

在本库里它按源的类型拆成两个子任务入口：

- **语音分离**：多人混合语音 -> 每人一路，细节见 [[方向/AI语音/知识/基础概念/SS（语音分离）|SS（语音分离）]]。
- **音乐源分离（MSS）**：一首歌曲 -> 人声 / 伴奏（或更细的鼓、贝斯等 stem），常用基准是 MUSDB18。

边界：源分离输出的是**可听波形**，不是「谁在什么时候说话」的时间标注（那是 diarization）；也不是只保留一路主语音的降噪（那是 [[方向/AI语音/知识/基础概念/SE（语音增强）导论|语音增强]]）。

## 2. 子任务划分

| 子任务 | 混合里的源 | 输出 | 入口笔记 |
|---|---|---|---|
| 语音分离（SS） | 多个说话人 | 每人一路 | [[方向/AI语音/知识/基础概念/SS（语音分离）]] |
| 目标说话人提取（TSE） | 多人 + 目标线索 | 目标一路 | [[方向/AI语音/知识/基础概念/TSE（目标说话人提取）]] |
| 音乐源分离（MSS） | 人声 + 乐器 stem | 各 stem 一路 | 待建 |
| 引导源分离（GSS） | 多人 + 时间标注 | 各路音频 | [[方向/AI语音/知识/基础概念/GSS（引导源分离）]] |

## 3. 典型路线

- **经典 BSS**：ICA、NMF、CASA、[[方向/AI语音/知识/基础概念/Beamforming（波束形成）|beamforming]]，可解释、适合多通道，单通道强重叠上限有限。
- **判别式深度学习**：频谱 mask / deep clustering -> [[方向/AI语音/知识/基础概念/PIT（置换不变训练）|PIT]] 解决输出排列 -> Conv-TasNet 等时域端到端。
- **生成式 / 统一指令接口**：[[方向/AI语音/模型/AuK|AuK]] 把语音分离和音乐分离收进「自然语言指令 + 音频 -> 波形」的统一接口，目标源可用内容、顺序、响度、时间戳指定——介于 SS（输出所有源）与 TSE（给参考锁定目标）之间的新形态。

## 4. 关键来源

- [MUSDB18 - a corpus for music separation](https://arxiv.org/abs/1711.01437)
  - 内容定位：音乐源分离的标准评测语料（150 首歌，vocals / drums / bass / other 四 stem）。
  - 用途：MSS 子任务的基准锚点；AuK-VAE 音乐重建评测也用它（MUSDB18-HQ）。
  - 核验日期：2026-09-15
- [AuK Technical Report: An Open-Source Foundational Model for Speech Generation and Editing](https://arxiv.org/abs/2609.08936)
  - 内容定位：统一指令接口同时覆盖语音分离与音乐分离的近期实例。
  - 用途：说明源分离正从任务专用模型走向指令驱动的统一基座。
  - 核验日期：2026-09-15

## 5. 相关对象

- [[方向/AI语音/知识/基础概念/SS（语音分离）|SS（语音分离）]]：本页的 speech 侧子任务，工程难点（排列、人数、跨段一致性）与评估指标在该页展开。
