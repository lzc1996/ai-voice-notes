# Sample Rate（采样率）

## 1. 身份

采样率（sample rate，单位 Hz / kHz）是每秒对连续音频波形采样的次数，决定数字音频能表示的最高频率。核心依据是**奈奎斯特定理**：采样率必须 ≥ 信号最高频率的 2 倍才能无失真还原，可表示的频率上限 = 采样率 / 2（奈奎斯特频率）。不要和 [[知识wiki/数学/Nyquist criterion（奈奎斯特准则）|奈奎斯特准则]] 混淆；后者通常指通信里的零 ISI 脉冲成形条件。

边界：采样率只决定**频率上限**，不决定量化精度（那是位深 bit depth 的事）；高采样率 ≠ 信息量多，超过信号实际带宽的部分只是冗余。

## 2. 常见档位

人耳听力上限约 20 kHz，人声有效信息主要在 8 kHz 以内，由此形成各档分工：

| 采样率 | 典型场景 | 理由 |
|---|---|---|
| 8 kHz | 传统电话（PSTN） | 人声可懂度够用最省带宽，有效频率 4 kHz |
| **16 kHz** | **语音识别、语音增强、说话人任务** | 语音任务事实标准：8 kHz 有效频率覆盖几乎全部语音信息，数据与算力减半 |
| 22.05 / 24 kHz | 早期 TTS、部分 codec | 折中档，兼顾一定音质 |
| 44.1 kHz | CD 音质、音乐 | 覆盖完整人耳范围（奈奎斯特频率 22.05 kHz） |
| 48 kHz | 专业音频、视频配乐、现代 TTS/codec | 比 44.1k 多余量，工程时钟更友好 |

## 3. 为什么语音模型几乎清一色 16 kHz

- **信息论**：音素、基频、共振峰等关键信息集中在 300 Hz–8 kHz，更高频对"听懂内容/辨别说话人"贡献很小；
- **成本**：相比 44.1 kHz，16 kHz 每秒样本数少 64%，序列长度、显存、延迟同比受益；
- **生态惯性**：[[方向/AI语音/模型/WavLM|WavLM]]、[[方向/AI语音/模型/HuBERT|HuBERT]]、wav2vec 2.0 都在 16 kHz 上预训练，下游用它们做冻结前端就必须跟随——[[方向/AI语音/模型/UniSE（Unified Speech Enhancement）|UniSE]] 所有音频统一重采样到 16 kHz 正是这个原因。

## 4. 两个注意点

- **"越高越好"有边际效应**：语音任务从 16 kHz 提到 48 kHz，提升主要在高频空气感/金属音细节，对识别、分离等任务收益甚微；音乐和高保真 TTS 才值得。
- **重采样方向不对称**：高采样率降到 16 kHz 几乎无损（信息本来在低频）；8 kHz 升到 16 kHz **不会**凭空多出高频信息。带宽限制是一种真实失真——UniSE 训练时专门模拟 2/4 kHz 带宽限制，让模型学会补全高频（bandwidth extension）。

## 5. 一句话

语音智能任务认 16 kHz，音乐/高保真认 44.1/48 kHz，电话遗留 8 kHz——选档依据永远是"信号里最高有用频率 × 2，再留点余量"。

## 6. 相关对象

- [[方向/AI语音/知识/基础概念/Spectrogram（声谱图）|Spectrogram（声谱图）]]：采样率决定 STFT/频谱表示的频率上限。
- [[方向/AI语音/模型/WavLM|WavLM]]、[[方向/AI语音/模型/HuBERT|HuBERT]]：16 kHz 预训练塑造了语音 SSL 生态的采样率标准。
- [[方向/AI语音/模型/UniSE（Unified Speech Enhancement）|UniSE]]：16 kHz 统一重采样 + 带宽限制失真模拟的实例。
- [[方向/AI语音/知识/基础概念/NAC（神经音频 Codec）|NAC（神经音频 Codec）]]：现代 codec 逐步转向 24/48 kHz 以支撑高保真重建。
- [[方向/AI语音/知识/基础概念/Full-Band（全频带）|Full-Band（全频带）]]：采样率之外的有效带宽口径——48 kHz 采样不等于全频带；NB/WB/SWB/FB 四档谱系见该页。
