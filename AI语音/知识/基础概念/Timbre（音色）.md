# Timbre（音色）

## 1. 身份

`Timbre`（音色）是声音的**听感属性**：在音高、响度和时长相近时，人仍能分辨两个声音“不是同一种声音”，这部分差异通常归入音色。

在语音里，音色描述“这个人听起来是什么质感”，包括明亮 / 发闷、厚 / 薄、气声 / 紧、鼻音、沙哑、金属感等。它不是单一物理量，也不等同于说话人身份：同一个人会因情绪、发声方式、麦克风、房间和增强处理而改变音色。

## 2. 声学组成

```text
声源激励：F0、谐波、噪声、声门形状
  -> 声道滤波：formant、spectral envelope、鼻腔耦合
  -> 动态与传输：起音/瞬态、能量包络、相位、麦克风/房间响应
  -> 听感：音色、自然度、说话人“像不像”
```

工程上常拆成几组线索：

- **谱包络 / formant**：决定大量共振结构、明暗、元音和声道色彩。
- **谐波结构与频谱倾斜**：影响厚薄、明亮度、气声和声门状态的听感。
- **F0 与谐波细节**：F0 主要决定音高，但谐波相对能量也参与音色。
- **时间包络与瞬态**：起音、辅音爆破、摩擦噪声和能量变化影响声音的“质地”。
- **噪声与非周期成分**：气声、沙哑、粗糙感等往往来自非周期激励和谐波噪声比变化。
- **通道染色**：麦克风、房间、codec、vocoder 和播放链路会改变原始音色。

## 3. 和相邻概念的区别

| 概念 | 主要回答什么 | 和音色的关系 |
|---|---|---|
| 音高 / [[方向/AI语音/知识/基础概念/F0（基频）]] | 声音有多高或多低 | F0 是音色的一个声源线索，但音高不等于音色 |
| 响度 / [[方向/AI语音/知识/基础概念/Level（电平）]] | 声音有多大 | 改变电平通常不应改变音色，但过载会产生失真和新音色 |
| [[方向/AI语音/知识/基础概念/Formant（共振峰）]] | 哪些频段被声道共振放大 | formant 是音色的重要组成，不是音色全部 |
| [[方向/AI语音/知识/基础概念/Spectral Envelope（频谱包络）]] | 频谱的平滑外形 | 谱包络包含大量音色信息，但还缺少瞬态、相位和时间变化 |
| 说话人身份 | “是谁在说” | 音色是身份线索之一，但身份还依赖更稳定的说话人特征与上下文 |
| 语音内容 | “说了什么” | 音色和内容正交；音色保持好不代表 WER / CER 正确 |

## 4. 在 AI 语音里的用途

- **TTS / voice cloning**：参考音频或 speaker embedding 提供音色条件；文本决定内容，音色条件决定“谁来读”。
- **Voice conversion**：通常保留源语音内容和韵律，改变目标音色 / 说话人特征。
- **语音增强 / 恢复**：目标不是把声音变成“更好听的新声音”，而是在去噪、去混响、带宽扩展后尽量保持原音色。
- **codec / vocoder**：tokenizer、latent 和 decoder 的信息瓶颈会决定哪些音色细节能保留，重建链路会决定最终音色上限。
- **诊断与评估**：看 `SpkSim`、speaker embedding similarity、NISQA `Coloration`、频谱包络 / formant 差异和人工 ABX / MOS；单一指标不能覆盖完整音色感知。

## 5. 常见误区

- **音色不是频谱包络的同义词**：谱包络很重要，但音色还受时间包络、谐波细节、噪声、相位和回放链路影响。
- **音色不是音高**：提高 F0 会改变音高，也可能带来音色联动，但不能把两个概念混成一个。
- **音色像不代表内容对**：voice cloning 或增强结果可能很像目标说话人，却出现漏词、错词或音素改写。
- **SpkSim 不是完整音色真值**：它依赖 speaker encoder，可能漏掉情绪、韵律、局部高频和通道染色。
- **“更亮”不一定更自然**：生成式增强补高频可能提升清晰度，也可能制造刺耳的假高频或改变说话人质感。

## 6. 相关对象

- [[方向/AI语音/知识/基础概念/Spectral Envelope（频谱包络）]]：音色最重要的频谱结构入口之一。
- [[方向/AI语音/知识/基础概念/Formant（共振峰）]]：声道共振和元音 / 音色结构。
- [[方向/AI语音/知识/基础概念/F0（基频）]]：声源频率与谐波结构线索。
- [[方向/AI语音/知识/基础概念/Level（电平）]]：响度、电平与失真的边界。
- [[方向/AI语音/评估/SpkSim]]：说话人 / 音色保持的嵌入相似度代理指标。
- [[方向/AI语音/知识/基础概念/Vocoder（声码器）]]：从声学条件或 latent 重建波形，决定最终音色上限。
- [[方向/AI语音/知识/基础概念/Microphone Channel Modeling（麦克风信道建模）]]：设备与房间频响可能给原始音色染色。
- [[方向/AI语音/知识/基础概念/Zero-shot Voice Cloning（零样本声音克隆）]]：从参考音频迁移目标音色的任务入口。
