# Haas Effect（哈斯效应）

## 1. 身份

Haas effect（哈斯效应），北美文献多称 **precedence effect（优先效应）**：两个高度相关的声音先后到达、间隔在几毫秒到几十毫秒时，听觉系统把它们**融合成一个事件**，声源方向由**先到的那一路**决定；后到声只贡献响度、宽度与音色，不形成独立回声。工程上常用的一句话概括是 Cremer 的**第一波前定律**（law of the first wavefront）：方向由最先到达的波前决定。

命名与出处：Helmut Haas 的博士研究（1949）以德文发表于 *Acustica*（1951），英译载 *J. Audio Eng. Soc.*（1972）。欧洲习惯称 Haas effect，北美习惯称 precedence effect；严格说 precedence effect 在心理声学里是更大的机制家族（含 summing localization、localization dominance、echo suppression），Haas effect 常指其中最直观的"延迟声增强响度而不产生回声"部分。

边界：它不是回声消除，也不是"延迟叠加"本身；它是**知觉层面的融合与方向加权**。物理上两路信号照样叠加、照样产生梳状滤波，听觉系统只是不把它们拆成两个声源。

## 2. 时间窗与主观结果

近似区间，实际阈值随信号类型、声级、频谱相关性与个体变化：

| 延迟 | 主观结果 |
| ---- | -------- |
| 0–1 ms | 两路叠加，声像位于两者之间（summing localization），同时出现梳状滤波 |
| 1–5 ms | 融合为单一事件，声像几乎完全由先到者决定 |
| 5–约 35 ms | 先到者主导方向；后到声提升响度、加宽声像，不形成独立回声（典型 Haas 区） |
| 超过约 40–50 ms | 越过回声阈值，后到声可能被听成独立回声 |

声级条件：在融合窗内，后到声可比先到声高约 10 dB 仍不被识别为回声（Haas 的原始结论）；多次反射场景的容限更高，后续研究报告到约 12 dB 量级。延迟一旦超过阈值，声级差不再是"是否融合"的主要判据。

机制解释仍未完全定论：主流假说包括对后到声的抑制/适应（双耳与单耳两条通路都有贡献），以及听觉系统对起始瞬态的优先编码；本页只记录现象与工程后果，不展开神经机制。

## 3. 与相邻概念的边界

- **ITD / ILD**：它们是**定位线索**；优先效应是当线索互相矛盾（直达声与反射声来自不同方向）时，听觉系统**给先到者加权**的机制。
- **回声阈值（echo threshold）**：融合失效的边界；Haas 区就是"阈值之内"的区间。
- **梳状滤波（comb filtering）**：两路叠加的**物理结果**，与优先效应同时发生，但属于线性系统现象。它解释延迟声造成的音色变化，不解释方向判断。
- **AEC（声学回声消除）**：工程上的电声回声路径消除；本页讨论的是听觉融合。两者只在"回声"一词上重叠，对象完全不同。
- **混响**：早期反射若落在融合窗内会被"吸收"进直达声事件；晚期混响落在窗外，构成混响感。

## 4. 在语音与空间音频中的位置

- **双耳渲染 / Ambisonics 解码**：HRTF 解码后的双耳信号里，直达声先到、反射后到，方向感由直达声主导；但叠加造成的梳状滤波会改变音色——"方向对、音色不对"是常见现象。
- **去混响 / 语音增强**：优先效应说明压制早期反射对可懂度收益有限，而压制晚期混响与噪声更关键；也说明"保留直达声"比"保留总能量"更接近听觉目标。
- **扩声系统**：延时补声（delay tower）按 Haas 原理设延迟，让听众仍把声像定位在舞台；延迟设错会把声像拉到补声喇叭上。
- **立体声加宽**：一路延迟 5–30 ms 甩到另一声道可制造宽度感，代价是单声道兼容性变差（梳状滤波）。

## 5. 使用注意

- **融合有前提**：两路需高度相关、延迟在窗内、声级差不过大；频谱差异大或延迟超阈值即失效。
- **别把"加延迟"当成无条件加宽**：单声道叠加会产生梳状滤波，听感变"空"或带"金属味"。
- **阈值不是常数**：语音、音乐、噪声、短脉冲的回声阈值不同；儿童、听障者、助听器或人工耳蜗用户的优先效应也可能不同，本页不展开。
- **与 AEC 术语区分**：工程文档里的 "echo cancellation" 指回声路径消除，不是 Haas 效应。
