# Formant（共振峰）

## 1. 身份

`Formant`（共振峰）是语音频谱 / [[方向/AI语音/知识/基础概念/Spectral Envelope（频谱包络）]] 上由声道共振形成的能量峰值。它主要反映口腔、咽腔、鼻腔等 vocal tract 的滤波形状，是区分 [[方向/AI语音/知识/基础概念/Vowel（元音）]]、音色和部分发音方式的重要声学线索。

边界：formant 不是 [[方向/AI语音/知识/基础概念/SPL（声压级）|响度]]，也不是 [[方向/AI语音/知识/基础概念/F0（基频）|pitch / F0]]。[[方向/AI语音/知识/基础概念/F0（基频）]] 描述声带振动基频和谐波间距；formant 描述声道滤波后哪些频段被放大。一个人用同一个 F0 发不同 [[方向/AI语音/知识/基础概念/Vowel（元音）]]，主要差别就在 formant 结构。

## 2. 直觉

语音常用 source-filter 模型理解：

```text
声源 source：声带振动 / 噪声激励，决定 [[方向/AI语音/知识/基础概念/F0（基频）]]、谐波、清浊音
声道 filter：口腔 / 咽腔 / 鼻腔形状，决定 formant 和频谱包络
输出 speech：source 经 vocal-tract filter 塑形后的波形
```

在 [[方向/AI语音/知识/基础概念/Spectrogram（声谱图）]] 上，formant 通常表现为随时间变化的较宽暗色频带，而不是一根根细谐波线。宽暗带是一片较厚、连续、略模糊的能量增强区；细谐波线是很多窄、平行、间距均匀的横线，间距约等于 [[方向/AI语音/知识/基础概念/F0（基频）]]。

## 3. 常见符号

- $F_1$：第一共振峰，常和元音开口度 / 舌位高低相关；开口更大时 $F_1$ 往往更高。
- $F_2$：第二共振峰，常和舌位前后、唇形相关；前元音$F_2$ 通常更高。
- $F_3$：第三共振峰，常用于分析卷舌、儿化、某些音色和说话人线索。
- $F_0$：[[方向/AI语音/知识/基础概念/F0（基频）|基频]]，不是 formant；但高 $F_0$ 会让 formant 估计更难。

同一时刻按频率编号时应满足 `F1 < F2 < F3`。如果看起来 `F2` 在 `F3` 上方，通常不是正常发音结构，而是红点未标号导致误读、跨时间点比较、自动 tracking 换轨，或参数 / 噪声 / 高 F0 造成的估计错误。真正可解释为发音线索的情况多是 `F3` 向下靠近 `F2`，例如儿化 / 卷舌。

## 4. F1/F2/F3 怎么解释

| 共振峰 | 主要反映 | 频率高通常表示 | 频率低通常表示 |
|---|---|---|---|
| `F1` | 元音开口度 / 舌位高低 | 嘴更开、舌位更低，如 /a/ | 嘴更闭、舌位更高，如 /i/、/u/ |
| `F2` | 舌位前后 / 唇圆程度 | 舌位更靠前，如 /i/、/e/ | 舌位更靠后或更圆唇，如 /u/、/o/ |
| `F3` | 更细的音色、卷舌 / 儿化线索 | 通常不单独决定普通元音类别 | 明显降低常见于 /r/ 色彩、卷舌或儿化 |

直觉上，`F1` 更像看“嘴张多大”，`F2` 更像看“舌头靠前还是靠后”。`F3` 对普通元音分类不如 `F1/F2` 直接，但对英语 /r/、普通话儿化和说话人音色细节很有用。不同说话人的声道长度不同，绝对数值会变；跨人比较时更看相对变化和同一说话人内部对比。

典型元音读图：/i/ 通常 `F1` 低、`F2` 高；/u/ 通常 `F1` 低、`F2` 低；/a/ 通常 `F1` 高、`F2` 中等；/e/ 通常 `F1` 中低、`F2` 较高；/o/ 通常 `F1` 中等、`F2` 较低。

## 5. 怎么看

- **Praat 手工看**：打开音频，显示 spectrogram 和 formant tracks，逐帧核对红点 / 曲线是否跟暗色频带一致。
- **LPC 自动估计**：formant tracking 多基于 LPC / Burg 等谱包络估计；参数不对会漂。
- **元音空间**：常用 $F_1$-$F_2$ 平面比较 [[方向/AI语音/知识/基础概念/Vowel（元音）]] 分布、说话人差异、方言差异和发音变化。
- **开口度**：看稳定元音核心的 `$F_1$`；`$F_1$` 越高通常越开口 / 舌位越低，`$F_1$` 越低通常越闭口 / 舌位越高。
- **增强前后对比**：看 noisy / enhanced / clean 的 formant 是否保留；生成式增强如果改写元音，通常会在 formant 结构上暴露。

详细 Praat 操作步骤见 [[方向/AI语音/工具/Praat（语音学分析工具）#5.3. 看 Formant]]。

## 6. 常见参数坑

- **Max formant**：成人男声常从 5000 Hz 起试，女声 / 儿童 / 高音歌声可能要更高；设太低会漏高频共振峰，设太高会把谐波误当 formant。
- **Number of formants**：常看前 4-5 个；数量过多会过拟合，过少会漏峰。
- **Window length**：窗口太短频率分辨率差，太长会抹掉快速发音变化。
- **F2/F3 换轨**：如果看起来 `F2` 高于 `F3`，或 `F2`、`F3` 在稳定元音核心反复交错 / 跳到细谐波线上，先用 `Query` 读同一时刻的数值，再调 `Max formant` 和 `Number of formants`，不要直接把红点当真值。
- **高 [[方向/AI语音/知识/基础概念/F0（基频）]] 场景**：儿童、女高音、歌声、情绪强烈语音的谐波间距大，formant 轨迹容易不稳定。
- **噪声 / 混响 / 增强伪影**：LPC 会把噪声峰、房间响应或模型伪影误估为声道峰。

## 7. 在 AI 语音里的用途

- **语音增强**：formant 保留关系到元音身份、可懂度和音色自然度；增强后“听起来干净但像换了元音”通常是危险信号。
- **TTS / 声码器**：自然语音需要合理的 formant 轨迹；过平滑会发闷，错误迁移会改变音色或元音。
- **Voice conversion**：formant shifting 可改变听感音色，但过度会破坏 intelligibility 和 speaker consistency。
- **评估诊断**：PESQ / STOI 不一定解释具体听感问题，formant 可作为人工诊断维度。

## 8. 相关对象

- [[方向/AI语音/知识/基础概念/Spectral Envelope（频谱包络）]]：formant 是谱包络上的主要峰值结构。
- [[方向/AI语音/知识/基础概念/Timbre（音色）]]：formant 结构是音色的重要组成，但不是音色的全部。
- [[方向/AI语音/知识/基础概念/F0（基频）]]：F0 是声源频率线索，formant 是声道共振线索。
- [[方向/AI语音/知识/基础概念/Vowel（元音）]]：元音身份最常用 `$F_1$`、`$F_2$` 和动态 formant 轨迹来分析。
- [[方向/AI语音/知识/基础概念/Spectrogram（声谱图）]]：formant 在声谱图上表现为连续频带。
- [[方向/AI语音/工具/Praat（语音学分析工具）]]：最方便的 formant 手工查看和校验工具。
- [[方向/AI语音/知识/基础概念/Vocoder（声码器）]]：声码器输出质量会影响 formant 和音色自然度。
- [[方向/AI语音/评估/STOI 与 ESTOI]]：可懂度与短时谱包络相关，formant 是其中关键结构之一。
