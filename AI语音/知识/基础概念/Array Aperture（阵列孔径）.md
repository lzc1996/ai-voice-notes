# Array Aperture（阵列孔径）

## 1. 身份

Array Aperture（阵列孔径）是麦克风阵列在空间中的有效尺寸，最常见定义是阵列中任意两个麦克风之间的最大距离：

$$
D = \max_{i,j} \|r_i - r_j\|
$$

其中 $r_i$ 是第 $i$ 个麦克风的位置，$D$ 是孔径。线阵里孔径近似等于首尾麦克风距离；圆阵里常看直径；分布式阵列里还要看目标方向上的有效基线。

边界：阵列孔径不是阵元间距。**阵元间距**主要决定高频空间混叠 / 栅瓣风险；**阵列孔径**主要决定方向分辨率、低频指向性和波束宽度。

## 2. 为什么重要

- **低频指向性**：当孔径 $D$ 远小于波长 $\lambda$ 时，各麦克风看到的相位差很小，低频很难形成有效波束。
- **角分辨率**：孔径越大，主瓣越窄，越容易区分相近方向的声源；粗略直觉是波束宽度随 $\lambda / D$ 变小。
- **硬件上限**：手机、耳机、眼镜这类小孔径设备天然低频空间信息弱；会议阵列、分布式阵列更容易获得低频方向性。
- **模型泛化**：固定阵列模型常把 IPD、通道顺序、通道数和孔径绑在一起，换设备后空间线索分布会变。

## 3. 和阵元间距的分工

阵列设计里通常同时看两个尺度：

- **最大孔径 $D$**：决定能否在低频形成足够窄的方向响应。
- **相邻阵元间距 $d$**：决定高频是否出现空间混叠；常见经验是 $d \le \lambda / 2$ 才能避免目标频率上的栅瓣。

因此，“孔径大”不等于“阵列一定好”。如果为了拉大孔径而让局部间距过大，高频会出现空间混叠；如果孔径很小，即使阵元间距合理，低频也缺少可用方向差。

## 4. 语音工程直觉

- 1 kHz 声波波长约 34 cm，小型手机/耳机阵列通常已偏小；300 Hz 波长约 1.1 m，对低频男声基频和房间低频噪声更难形成强方向性。
- 小孔径阵列更依赖神经后滤波、声源先验或近场线索；大孔径阵列更适合做稳定的 DOA、beamforming 和空间分离。
- 分布式多设备阵列理论上孔径大，但同步、延迟漂移、坐标标定和时钟误差会变成主要成本。
