# Tolerance Line（容差线）

## 1. 身份

`Tolerance Line`（容差线）是在基线、参考曲线或同类样本分布周围画出的可接受偏差边界。它用于把连续指标变成“正常 / 可疑 / 异常”的判断，而不是替代原始指标。

边界：容差线不是指标本身，也不是通用常数。它依赖任务、数据集、评分器版本、采样率、语言、设备链路和人工听感标准。很多场景实际用的是上下两条线组成的 `Tolerance Band`（容差带）。

## 2. 直觉

```text
参考值 / 基线 b(x)
上容差线 b(x) + τ
可接受区间
下容差线 b(x) - τ
```

一个样本落在容差带内，说明偏差还可以先当成正常波动；超出容差线，才值得进入异常解释、人工听感抽检或模型回归分析。

## 3. 在语音增强评价里的用途

- **指标冲突筛选**：`z(DNSMOS_OVRL) - z(NISQA_MOS)` 超出容差线时，优先抽样听，避免过度解释小分差。
- **子维度异常**：`NISQA Coloration` 低于同类样本下容差线时，优先检查 [[方向/AI语音/知识/基础概念/Boxy Sound（箱音）]]、[[方向/AI语音/知识/基础概念/High-Frequency Roll-off（高频滚降）]] 或其他音色染色。
- **频谱诊断**：增强后高频能量或谱包络斜率低于参考容差线时，可标为高频滚降候选，而不是直接下结论。
- **人工标注准入**：只把超过容差线的样本送入“箱音 / 高频滚降 / 断续 / 响度异常”标签池，减少主观标签噪声。

## 4. 常见设法

- **固定偏差**：例如相对基线差 `0.3 MOS` 才算异常；简单，但跨数据集迁移差。
- **分布分位数**：用同类样本残差的 `P5 / P95` 或 `P10 / P90` 作为上下容差线；适合批量实验。
- **标准差倍数**：用 `mean ± k·std`；实现快，但对长尾异常敏感。
- **分桶容差线**：按 SNR、说话人、语言、设备、噪声类型分别标定；更稳，但需要更多样本。

最小可用版本：先对指标做 z-score，再按同一测试集残差的上下分位数画线。

## 5. 容易混淆

- **阈值**：单点判断边界；容差线通常是围绕基线或分布的相对边界。
- **基线**：参考水平；容差线是在基线上方 / 下方定义可接受偏差。
- **容差带**：上下容差线之间的区间；实际解释时比单条线更常用。
- **置信区间**：统计估计的不确定性；容差线是工程可接受范围，两者可以相关但不等价。
- **控制线**：质量控制中的过程异常线；容差线更强调任务可接受边界。

## 6. 相关对象

- [[方向/AI语音/评估/语音增强评估指标体系]]：容差线适合放在多指标诊断层，用来筛冲突样本。
- [[方向/AI语音/评估/NISQA]]：可对 MOS 与四个子维度的残差设置容差线。
- [[方向/AI语音/评估/OVRL_MOS]]：DNSMOS / OVRL 与 NISQA 的差值可用容差线筛查分歧。
- [[方向/AI语音/知识/基础概念/High-Frequency Roll-off（高频滚降）]]：频谱斜率或高频能量低于下容差线时，可作为候选诊断。
- [[方向/AI语音/知识/基础概念/Boxy Sound（箱音）]]：箱音标签可通过低中频堆积和高频不足的容差线辅助筛选。
- [[方向/AI语音/知识/基础概念/Spectral Envelope（频谱包络）]]：容差线可画在谱包络差异或频段能量差上。

## 7. 待验证

- 本地 DNSMOS / NISQA / SpkSim / SpeechBERTScore 的残差容差线应按全局、噪声类型还是说话人分桶标定。
- 用分位数容差线筛出的冲突样本，人工听感命中率是否高于直接按分数排序。
- 高频滚降、箱音、断续、响度异常是否需要各自独立容差线，而不是共用一个 MOS 差值阈值。
