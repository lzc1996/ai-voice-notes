# Audio Leakage（漏音）

## 1. 身份

音频处理里的“漏音”不是一个单一严格术语，常见有三种含义：

- **麦克风串入 / mic bleed / spill**：一个麦克风拾到非目标声源，比如多人播客里 A 的麦克风也收到 B 的声音。
- **扬声器到麦克风的声学泄漏**：播放端声音被麦克风重新收进来，形成回声、双声或远端听到自己的声音；通信链路里通常交给 [[方向/AI语音/知识/基础概念/AEC（声学回声消除）]] 处理。
- **对外声泄漏 / privacy leakage**：耳机、手机、会议室或设备发出的声音泄到外部，被旁人听到或被其他麦克风捕获。

边界：漏音和噪声、混响、回声、串扰有重叠，但不是同一件事。漏音强调“本不该进入这一路音频的信号进入了”；混响强调空间反射尾音；电气串扰强调通道间非声学耦合。

## 2. 常见场景

- 多人同室录音：每支麦克风都拾到其他说话人，后期合并时产生空洞感、梳状滤波或说话人分离困难。
- 电脑/手机外放开会：扬声器声音进麦克风，对端听到回声。
- 耳机隔音差：播放内容外泄，影响隐私，也可能被近场麦克风捕获。
- 语音 Agent 设备：TTS 播放声被 ASR 输入收回，造成自我触发、重复识别或打断判断错误。
- 远场 ASR：目标语音、背景播放声、电视声和房间反射混在一起，降低识别稳定性。

## 3. 处理思路

- **先物理隔离**：戴耳机、降低外放音量、拉开声源和麦克风距离、使用指向性麦克风、给多人各自近讲。
- **再做路由检查**：排除系统混音、声卡 loopback、虚拟声卡、监听返送或错误输入设备导致的“假漏音”。
- **通信链路用 [[方向/AI语音/知识/基础概念/AEC（声学回声消除）]]**：有播放参考信号时，优先用 AEC 抵消扬声器到麦克风的泄漏。
- **多人录音用自动混音/门限**：gate、expander、automixer 和说话人活动检测可以降低非目标轨道的泄漏，但会牺牲自然度。
- **模型后处理**：源分离、说话人分离、[[方向/AI语音/知识/基础概念/TSE（目标说话人提取）|目标说话人提取]]、[[方向/AI语音/知识/基础概念/Reverse TSE（反向目标说话人提取）|反向目标说话人提取]]和语音增强能补救部分漏音，但不要当成首选方案。

## 4. 评估指标

- 泄漏声相对目标声的电平差：越低越好，常用 dB 表示。
- Echo Return Loss / ERLE：看 AEC 对回声路径的抑制程度。
- ASR 侧影响：误触发率、重复转写、非目标说话人转写、WER/[[方向/AI语音/评估/CER（Character Error Rate）|CER]] 增量。
- 主观听感：是否有双声、空洞感、相位感、残留回声或门限抽吸感。

## 6. 相关对象

- [[方向/AI语音增强/README|AI 语音增强]]：漏音常被当成增强、分离或[[方向/AI语音/知识/基础概念/TSE（目标说话人提取）|目标说话人提取]]的输入污染问题。
- [[方向/AI语音/知识/基础概念/AEC（声学回声消除）]]：有播放参考时，处理扬声器回灌到麦克风的首选模块。
- [[方向/AI语音/知识/基础概念/Reverse TSE（反向目标说话人提取）|反向目标说话人提取]]：已知泄漏说话人时，可尝试定向抑制该声源。
- [[方向/AI语音/MOC - ASR|ASR]]：漏音会造成误触发、重复转写和非目标说话人进入识别结果。
- [[方向/AI语音/MOC - TTS|TTS]]：语音 Agent 中 TTS 外放可能被 ASR 收回，形成自触发链路。
- [[方向/AI语音/知识/基础概念/Reverberation Modeling（混响建模）|混响建模]]：漏音进入房间后还会叠加反射和晚期混响。
