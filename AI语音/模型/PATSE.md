# PATSE（位置感知目标说话人提取）

## 0. 背景

**问题现场**：长时多方对话中说话人活跃度高度不均衡、重叠频繁，"谁在说、说了什么"难以确定，需要按说话人归属的转写前端。

**前序路线的缺口**：滑窗连续语音分离（CSS）存在跨窗说话人不一致与残留串扰，实践中仍需 diarization 才能可靠归属说话人。

**PATSE 的切入点**：利用会议中说话人方向随时间稳定的事实，以 DOA 为空间先验与身份锚点直接逐人抽取语音，把"抽取"与"归属"合并为一步，免显式 diarization。

## 1. 身份

`PATSE`（Position-Aware Target Speaker Extraction）是 2026-06 挂上 arXiv（arXiv:2606.29497，v1 2026-06-28）的**多通道位置感知目标说话人提取前端**：面向长时多方对话（说话人活跃度高度不均衡、重叠频繁，"谁在说、说了什么"难以确定），以 [[方向/AI语音/知识/基础概念/DOA（到达方向）|DOA]] 为空间先验直接抽取每个目标说话人的语音，输出**按说话人归属的流（speaker-attributed streams）**；说话人活跃区间只需简单后处理（如 [[方向/AI语音/知识/基础概念/VAD（Voice Activity Detection）|VAD]]）即可推断，**免显式 diarization**。

动机：滑窗连续语音分离（CSS）虽缓解了稀疏监督问题，但存在**跨窗说话人不一致**与**残留串扰**，实践中仍需 diarization 才能可靠归属说话人；PATSE 利用会议中说话人方向随时间稳定这一事实，用位置把"抽取"与"归属"合并为一步。

边界：不是纯 SE——属 [[方向/AI语音/知识/基础概念/TSE（目标说话人提取）|TSE]] / diarization 相邻的抽取前端（调研页口径："和增强共享阵列前端，但任务不是纯 SE"）；不是先分离全部说话人再归因，而是按位置直接逐人抽取。团队与机构待确认（摘要页仅见提交人 Wangjin Zhou）。

## 2. 核心机制

1. **DOA 作空间先验与身份锚点**：利用会议场景中说话人方向稳定的事实，用每个目标说话人的 DOA 标识其身份，替代注册语音或 diarization 标签。
2. **DOA 引导的空间编码器 + 条件器（conditioner）**：空间编码器提取方向相关特征，条件器按目标 DOA 调制，直接生成该说话人归属的输出流。
3. **免 diarization 的活跃检测**：各路输出流本身已按说话人归属；说话人活跃区间由简单后处理（如 VAD）推断，无需独立 diarization 模块。

```text
多通道混合输入（长时多方对话）
  -> 各目标说话人 DOA（会议内稳定的空间先验）
  -> DOA 引导空间编码器 + 条件器（按 DOA 逐人抽取）
  -> 按说话人归属的输出流 × N
  -> 简单后处理（VAD 等）-> 说话人活跃区间（替代显式 diarization）
  -> 下游 ASR
```

## 3. 结果口径

- 摘要级：在**重放（replayed）与真实（real）会议对话**上均取得一致的 ASR 收益，优于 CSS 管线与基于 diarization 的管线。
- 具体指标（WER/cpWER 数值、语料构成、阵列配置、说话人数、与基线的量化差距）摘要未给出，待全文（见待验证）。

## 4. 使用判断

- 适合：长时会议 / 多方对话的 speaker-attributed ASR 前端；说话人位置相对稳定的阵列场景；希望省掉独立 diarization 环节的转写链路。
- 不适合：单通道输入；说话人位置频繁移动的场景；有注册语音可用的 enrollment 式单目标提取。
- 风险：DOA 估计误差直接传导为抽取与归属错误（说话人移动、多人方向接近时）；2026-06 刚出，仅摘要级证据，待全文与复现验证。
