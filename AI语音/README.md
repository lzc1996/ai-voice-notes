# AI语音目录组织规则

本目录按两层职责分工：**外层放稳定对象，`知识/` 放对象之上的整理层**。

## 外层：对象库

外层目录收可被反复引用的稳定对象。

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| `模型/` | 具体模型、系统、方法名 | 横向综述、路线判断 |
| `数据集/` | 数据集、语料库、数据源 | 数据清洗方法论 |
| `评估/` | 指标、benchmark、挑战赛、leaderboard | 领域综述 |
| `团队/` | 实验室、公司团队、作者组 | 团队地图 |
| `工具/` | 可直接使用的软件、库、分析工具 | 抽象机制 |
| `信息源/` | 会议、期刊、网站、资料入口 | 单篇论文 |
| `实证研究/` | 非模型论文证据页：假设验证、机制分析、对比评测等实证发现 | 介绍命名模型/系统的论文（进 `模型/`） |
| `选型/` | 面向决策的模型/方案选择 | 纯事实对象页 |
| `思考/` | 尚未稳定成路线或结论的个人问题 | 可复用对象 |

## `知识/`：整理层

`知识/` 不承载具体对象本体，只承载跨对象抽象。

| 目录 | 放什么 | 判断问题 |
|---|---|---|
| `基础概念/` | 稳定术语、机制、数学/声学概念 | “这是什么？” |
| `技术路线/` | 方法族、训练配方、工程路径、阶段拆解 | “沿哪条路做？” |
| `调研与地图/` | 综述、SOTA、团队图谱、路线地图 | “领域现在长什么样？” |
| `生成式语音增强/` | 生成式 SE 专题整理层 | “生成式增强这条专题如何组织？” |

## 快速判定

- 能单独被横向对比的实体，放外层对象库。
- **单篇论文先问主角**：论文介绍了一个命名模型/系统（模型可被横向对比）→ `模型/`；论文的核心产出是实证发现（假设验证、机制分析、对比评测，无命名模型或模型非主角）→ `实证研究/`。同一模型族可以两页并存：对象页在 `模型/`，针对它的实证研究页在 `实证研究/`（如 FT-JNF）。
- 能解释多个对象共同规律的抽象，放 `知识/`。
- benchmark 和 challenge 属于 `评估/`，不是 `调研与地图/`。
- 工具属于 `工具/`，不是 `知识/工具/`。

> [!note] 命名沿革
> `实证研究/` 前身是 `论文/`（2026-10-29 改名）。改名原因：`模型/` 页本质也是论文笔记，"论文"命名掩盖了真实分界（有无命名模型主角）；AI语音是唯一设 `模型/` 对象库的方向，其他方向的 `论文/` 为泛论文目录，语义不同。
