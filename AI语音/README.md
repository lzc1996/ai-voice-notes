# AI语音目录组织规则

本目录按两层职责分工：**外层放稳定对象，`知识/` 放对象之上的整理层**。

## 外层：对象库

外层目录收可被反复引用的稳定对象。

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| `模型/` | 具体模型、系统、方法名 | 横向综述、路线判断 |
| `数据集/` | 数据集、语料库、数据源 | 数据清洗方法论 |
| `评估/` | 指标、benchmark、挑战赛、leaderboard | 领域综述 |
| `团队/` | 实验室、公司团队、作者组 | 团队地图 |
| `工具/` | 可直接使用的软件、库、分析工具 | 抽象机制 |
| `信息源/` | 会议、期刊、网站、资料入口 | 单篇论文 |
| `论文/` | 单篇论文证据页 | 已抽象成路线的方法族 |
| `选型/` | 面向决策的模型/方案选择 | 纯事实对象页 |
| `思考/` | 尚未稳定成路线或结论的个人问题 | 可复用对象 |

## `知识/`：整理层

`知识/` 不承载具体对象本体，只承载跨对象抽象。

| 目录 | 放什么 | 判断问题 |
|---|---|---|
| `基础概念/` | 稳定术语、机制、数学/声学概念 | “这是什么？” |
| `技术路线/` | 方法族、训练配方、工程路径、阶段拆解 | “沿哪条路做？” |
| `调研与地图/` | 综述、SOTA、团队图谱、路线地图 | “领域现在长什么样？” |
| `生成式语音增强/` | 生成式 SE 专题整理层 | “生成式增强这条专题如何组织？” |

## 快速判定

- 能单独被横向对比的实体，放外层对象库。
- 能作为证据引用的单篇论文，放 `论文/`。
- 能解释多个对象共同规律的抽象，放 `知识/`。
- benchmark 和 challenge 属于 `评估/`，不是 `调研与地图/`。
- 工具属于 `工具/`，不是 `知识/工具/`。
