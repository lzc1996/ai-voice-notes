# CER（Character Error Rate）

## 0. 背景

**问题现场**：中文等不以空格分词的语言，"词"边界不唯一，词级错误率不稳定，需要字符级口径。

**切入点**：字符级编辑距离统计替换/删除/插入得到 CER，是中文 ASR 评估与 [[CAcc]]（1 − CER）的基础口径。

## 1. 身份

CER（Character Error Rate，字符错误率/字错率）是 ASR 评估指标，用字符级编辑距离衡量识别文本和参考文本之间的差异。

常用公式：

```text
CER = (S + D + I) / N
```

- `S`：substitution，替换字符数。
- `D`：deletion，漏掉字符数。
- `I`：insertion，多插入字符数。
- `N`：参考文本字符数。

## 2. 用途

- 中文 ASR 评估：中文没有天然空格分词，CER 通常比 WER 更直接。
- 多语言/代码切换评估：需要先明确英文单词、数字、标点和空格是否参与字符级计算。
- 小样本模型对比：适合作为底线准确率指标，但不能替代实体词、数字、时间戳、说话人和下游任务收益。

## 3. 计算口径

- 先固定归一化规则：繁简、大小写、全半角、标点、空格、数字读法、英文大小写。
- 再做字符级对齐：按编辑距离统计 `S/D/I`。
- 最后按参考字符数归一化：`N` 不是预测字符数。
- CER 可以超过 100%，常见原因是插入字符很多。

## 4. 最小例子

```text
reference: 今天下雨
hypothesis: 今天天雨

S = 1（下 -> 天）
D = 0
I = 0
N = 4
CER = 1 / 4 = 25%
```
