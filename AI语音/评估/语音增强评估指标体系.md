# 语音增强评估指标体系

语音增强的评估没有一个"够用的单一指标"。当前体系按**需不需要干净参考**和**衡量什么维度**组织成四大类；2025–2026 的核心现象是**指标分裂**——生成式模型刷满听感类指标的同时内容保持类指标崩塌，任何单一指标排名都不再有说服力。

## 1. 指标地图

### 1.1. 侵入式（需要干净参考）

| 指标 | 维度 | 范围 | 笔记 |
|------|------|------|------|
| [[PESQ]] | 感知质量 | −0.5–4.5 | 经典主指标，对生成式系统性失真 |
| [[STOI 与 ESTOI]] | 可懂度 | 0–1 | "听得清"而非"听得好" |
| [[SI-SDR]] | 波形保真 | dB | 纯信号度量，无感知模型；常作训练损失 |
| [[CSIG CBAK COVL（复合客观质量指标）|CSIG / CBAK / COVL]] | 信号/背景/总体质量 | 1–5 | PESQ 时代配套三件套，预测主观分维度；与 PESQ 高度共线 |
| POLQA | 感知质量（电信级） | 1–5 | PESQ 继任标准（P.863），商用工具 |

### 1.2. 非侵入式（无参考，模型预测）

| 指标 | 维度 | 特点 | 笔记 |
|------|------|------|------|
| DNSMOS（[[OVRL_MOS]]） | SIG/BAK/OVRL 三分 | P.835 结构，实时通话评测标配 |
| [[NISQA]] | MOS + 4 子维度 | 开源、可复现、子维度细 |
| [[UTMOS]] | MOS | 与主观 MOS 排名相关性最高（URGENT 2024 分析） |
| [[SCOREQ]] | MOS | 与 UTMOS 并列相关性第一档（URGENT 2024 分析） |
| QMOS | 质量 MOS | 生成式论文常用（DiTSE 4.34），口径随工具而异 |
| [[VQScore（语音质量评分）]] | 质量 / 数据筛选 | 更适合筛 clean target 和低质语音，不单独替代 MOS |

### 1.3. 内容/身份保持（幻觉探针）

| 指标 | 维度 | 说明 | 笔记 |
|------|------|------|------|
| [[CAcc]]（= 1 − CER） | 内容保持 | ASR 转写比对，检测"词被改写" |
| [[SpeechBERTScore（语音语义相似度）]] | 语义/表示相似度 | 在自监督语音特征上做 BERTScore 式参考匹配 |
| [[SpkSim]] | 说话人保持 | 嵌入余弦相似度，检测"不像本人" |
| WER | 下游 ASR 收益 | 英文词级口径；[[方向/AI语音/评估/CER（Character Error Rate）]] 为字级 |

### 1.4. 主观听测（金标准）

| 协议 | 说明 |
|------|------|
| P.808 | 众包 MOS 听测标准流程，URGENT/DNS 主观轮都用它 |
| P.835 | 语音/背景/总体三分开打分，DNSMOS 模仿的对象 |
| LPS（Levenshtein Phone Similarity） | 音素级内容保持，主观评测的补充 |

### 1.5. 效率/部署指标

| 指标 | 维度 | 说明 |
|------|------|------|
| [[NFE（函数评估次数）]] | 采样计算量 | 扩散 / Flow Matching 中神经网络函数被调用的次数；需和 RTF、首包延迟一起看 |
| [[RTF（实时率）]] | 实时率 | 推理耗时 / 音频时长；端到端部署更直接，但只代表吞吐不代表延迟 |
| 算法延迟 | 首包与流式延迟 | 通话链路需要统计 chunk、lookahead、vocoder / decoder 和 overlap-add |

## 2. 指标分裂：当前最重要的事实

[[方向/AI语音/评估/URGENT（通用语音增强挑战）|URGENT 2025]] 提供了教科书级案例（详见 [[SE SOTA（语音增强模型表现）]]）：

| 系统 | MOS | DNSMOS | PESQ | ESTOI | SpkSim | CAcc |
|------|-----|--------|------|-------|--------|------|
| 生成式 T13 | **3.69（第一）** | 第一 | 1.34 | 0.54 | 0.47 | 67.9% |
| 判别式 T1（总冠军） | 较低 | 较低 | 高 | 高 | 高 | ~89.9% |

- 生成式输出"听起来干净自然但内容被重新生成"：听感类指标（MOS/DNSMOS/[[NISQA]]/[[UTMOS]]）全部被骗过，参考类与内容类指标（[[PESQ]]/[[STOI 与 ESTOI|ESTOI]]/[[SI-SDR]]/[[CAcc]]/[[SpkSim]]）全面崩塌。
- 推论 1：**评测报告必须双轨**——听感类至少一个 + 内容/身份类至少一个。
- 推论 2：混合式（判别+生成）是同时满足两轨的当前最优解（URGENT 2026 双冠军）。
- 推论 3：非侵入式指标自身也需要用跨语言主观听测（P.808）定期标定——日语失配案例：NISQA 3.08 vs 主观 MOS 2.94。

## 3. 选型速查

- **离线高保真修复（有参考）：** PESQ + ESTOI + SI-SDR + SpkSim + CAcc，加非侵入式 DNSMOS/NISQA 对照。
- **真实录音（无参考）：** DNSMOS(SIG/BAK/OVRL) + NISQA + UTMOS，重要结论前补 P.808 人工听测。
- **生成式模型评审：** 听感类分数必须搭配 CAcc / SpeechBERTScore 和 SpkSim，否则无法排除幻觉。
- **面向下游 ASR：** 直接报告增强后 WER/CER，听感指标只作辅助。
- **训练损失选择：** SI-SDR / 多分辨率 STFT 损失管保真，感知损失（PESQ 可微代理、对抗损失）管听感，两者通常加权并用。

## 4. 指标组合诊断

- **指标差值超过 [[方向/AI语音/知识/基础概念/Tolerance Line（容差线）]]**：先进入冲突样本池，再结合 NISQA 子维度、SpkSim、CAcc / SpeechBERTScore 和人工听感标签解释原因。
- **CER / SpeechBERTScore 好、SpkSim 差**：内容和语义表示大体保住，但说话人身份 cues 可能被平滑、窄带化或变声；也可能是 reference 配对、采样率、VAD 或 speaker encoder 口径问题。先跑 [[SpkSim]] 的异常定位，再改训练。
- **听感高、CAcc / SpkSim 低**：典型生成式幻觉或身份漂移，不能只按 MOS / DNSMOS 判好。
- **WER / CER 好、PESQ / SI-SDR 低**：下游识别收益不等于波形保真；如果目标是 ASR 前端可以接受，如果目标是高保真修复则不够。
- **SpkSim 好、CER 差**：音色像本人但内容被改写，常见于生成式恢复或强去噪误删音素。
