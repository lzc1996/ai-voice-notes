# ELAN（多层语音视频标注工具）

## 1. 身份

`ELAN` 是多层音视频标注工具，适合给一段音频 / 视频建立多个时间对齐的 annotation tiers，例如说话人、文本、动作、事件、语气、重叠说话。

## 2. 什么时候用

- 需要人工构建小规模高质量标注集。
- 语音、视频、手势、行为事件需要在同一时间轴上对齐。
- 对 ASR / diarization / enhancement 的错误做细粒度人工分析。

## 3. 边界

- 它是人工标注工作台，不是自动模型。
- 大规模自动对齐先用 [[方向/AI语音/工具/MFA（强制对齐工具）]] 或 [[方向/AI语音/工具/WhisperX（长音频转写与对齐）]]，再抽样进 ELAN 修订。

## 4. 安装方式

- Windows：官网下载 `.exe` / `.msi` 安装，或下载 `.zip` 解压运行；官方包自带 Java runtime。
- Linux：下载 `.tar.gz` 解压运行，或 Debian/Ubuntu 使用 `.deb`；官方 Linux 包也自带 Java runtime。

## 5. 内网迁移

- Windows：优先拷 `.zip` 便携版；需要统一部署时拷 `.msi`。
- Linux：优先拷 `.tar.gz`；只有能离线处理依赖和包管理时才拷 `.deb`。
- 标注工程通常是 `.eaf` + 媒体文件，迁移时保持相对路径，避免内网机器打不开媒体。
