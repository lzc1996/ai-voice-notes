# NWPU ASLP Lab（西工大 ASLP 实验室）

## 1. 身份

西北工业大学 Audio, Speech and Language Processing Lab（[官网](https://www.npu-aslp.org/english)），国内语音大模型方向头部实验室之一（OSUM 等），在"LM 化语音增强"方向有代表作。单通道增强为主。

## 2. 代表作

- **[[方向/AI语音/模型/SenSE|SenSE]]**（ICME）：semantic-aware universal speech enhancement——LM 提取语义 token 注入 flow matching 增强，减少严重退化下的语义歧义（[GitHub](https://github.com/ASLP-lab/SenSE)，HF 权重 `ASLP-lab/SenSE`）。
- **OSUM**：开放语音理解大模型，实验室主线产品，语义/LLM 能力的底座。

## 3. 与阵列团队的交叉

- 未查到他家的多通道/阵列增强工作；交叉意义在于：SenSE 的"语义 token 指导生成式增强"范式可被嫁接到多通道前端之后（参见 [[方向/AI语音/知识/调研与地图/Array Speech Enhancement Team Map（阵列增强团队地图）|团队地图]] 交叉图谱）。

## 4. 可信度依据

- 权重/代码开放（Hugging Face + GitHub），可复现。
- 语音大模型方向持续产出，语义-声学联合建模是国内第一梯队。
