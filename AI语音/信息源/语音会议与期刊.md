# 语音会议与期刊

## 1. 内容定位

这里统一管理 AI 语音方向的一手论文入口：会议官网、proceedings、archive、journal 页面和年度跟踪页。不放在 `知识/` 下，避免把“信息源”混进概念笔记。

## 3. 经验来源与信息漏斗

- **挑战赛 / benchmark**：DCASE、MIREX、Papers With Code、URGENT、DNS、CHiME；重点看 task definition、metric、baseline 和技术报告，不只看排行榜。
- **开源 recipe**：ESPnet、SpeechBrain、torchaudio、Hugging Face Audio；优先查数据准备、采样率、VAD、metric、checkpoint 和训练脚本。
- **工程经验**：GitHub issue / discussion、challenge baseline、作者主页和实验室主页；适合定位 evaluation script bug、resampling、speaker encoder domain shift、checkpoint mismatch 这类问题。
- **最小漏斗**：每周扫 arXiv `eess.AS` / `cs.SD` / `cs.SL` + Interspeech / ICASSP / DCASE；每月复现一个 recipe；具体异常只查一篇综述、一份 baseline 代码、一个 challenge 技术报告。

## 4. 使用规则

- 查论文先看官方 archive / proceedings，再看 arXiv、GitHub 和二手榜单。
- 建年度页只在真的要跟踪 accepted papers、special sessions、challenge 或 keynote 时做。
- 不为每个会议名都拆独立对象页；只有反复使用或需要存年度来源时再拆。
- 论文条目仍归到对应模型、数据集、任务或方法笔记；这个索引只管入口。
